## Presets

Curated looks for `c2-progress`. Open any card in the studio to start from it. The bar is two boxes: `--c2-progress--height` and `--c2-progress--border-radius` give it its shape, the indicator and track colours give it its tone, and `--c2-progress--animation-duration` sets the pace of both the sweep and the fill.

The season pass card draws each reward through `renderMark`, whose output carries its own parts for the page to style. The French card announces each milestone's state ("1 500, à réclamer", "3 000, encore 1 200") once the application supplies the text:

```ts tag=CodeBlock
import { html } from 'lit'
import { addTranslations } from '@c2n/core/localize.js'

const season = document.querySelector('c2-progress')!
season.renderMark = ({ mark, state }) =>
  html`<span part="reward-level">${state === 'claimable' ? 'Claim' : `Lv ${mark.value}`}</span><span part="reward-name">${mark.label}</span>`

addTranslations({ fr: { progress: { markReached: '{0}, atteint', markClaimable: '{0}, à réclamer', markLocked: '{0}, encore {1}', markAhead: '{0}, pas atteint' } } })
```
