## Presets

Curated looks for `c2-theme-select`. Open any card in the studio to start from it. The trigger is shaped by the four
`__trigger` variables — size, radius, border and background — and the dropdown by `__menu` and `__menu-item`. Every
card is `manual` so trying it does not repaint this page.
