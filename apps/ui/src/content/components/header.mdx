`c2-header` owns site-shell layout without owning navigation state. Put a `c2-navigation-menu` in the default slot, use a real `c2-link-button` for navigation actions, and add as many end controls as needed to the `actions` slot. The action area handles spacing and alignment; `sticky` pins the shell and `blurred` adds its translucent backdrop treatment.

## Installation

Install the header plus the controls used by this composition.

```bash tag=CodeBlock
npm install @c2n/header @c2n/navigation-menu @c2n/link-button @c2n/button @c2n/icon-button @c2n/feather-icons
```
