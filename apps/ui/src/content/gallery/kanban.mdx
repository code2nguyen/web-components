## Presets

These boards use the default card renderer, so their whole look comes from variables: `--c2-kanban-column__card--*`
for the card box, the other `--c2-kanban-column__*` variables for the column, its header and the drop gap. Set them on
the board to reach every column. Give the board a `renderItem` for richer card content.

<GalleryGrid columns="1">

```html tag=MdxCodeBlock,label=Default
<c2-kanban
  client:only="lit"
  editable
  aria-label="Tasks"
  items='[{"id":"1","column":"todo","title":"Write the release notes"},{"id":"2","column":"todo","title":"Update the screenshots"},{"id":"3","column":"done","title":"Fix the build"}]'
>
  <c2-kanban-column column-id="todo" label="To do"></c2-kanban-column>
  <c2-kanban-column column-id="done" label="Done"></c2-kanban-column>
</c2-kanban>
```
