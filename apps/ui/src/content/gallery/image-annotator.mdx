## Review and pins

The same shapes, chosen rather than edited. `active` is the chosen shape; with `readonly selectable` a reviewer still picks shapes by click, Tab and the arrow keys, and `shape-select` reports each choice. A `label` names a shape, a `confidence` under `confidence-threshold` dashes it in the review colour, and the `detail` slot or `renderDetail` puts the app's card beside the active shape.

<ImageAnnotatorExamplesRuntime />

The form, the threads and the pin cards are the app's. A focused field makes its region active; `shape-select` swaps the thread; `renderDetail` draws a card from the active shape:

```ts tag=CodeBlock
const annotator = document.querySelector('c2-image-annotator')!

// Extraction review: the focused form field drives the highlight, a button steps through the regions.
form.addEventListener('focusin', (event) => (annotator.active = (event.target as HTMLElement).dataset.field ?? null))
nextButton.addEventListener('click', () => fieldFor(annotator.next())?.focus())

// Pinned comments: the thread in the detail slot follows the chosen pin.
annotator.addEventListener('shape-select', (event) => {
  if (event.detail.id) thread.comments = threads[event.detail.id] ?? []
})

// Image pins: a card drawn from the pin.
annotator.renderDetail = ({ shape, index, count }) => html`<strong>${shape.label}</strong> · pin ${index + 1} of ${count}`
```
