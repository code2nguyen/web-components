`c2-tree-table` is [`c2-table`](/web-components/components/table) with rows nested to any depth (`children-field`).
Everything else, from columns, sorting and selection to windowing, paging, the summary row, editing and realtime
updates, is the table's, and works the same here. Use `c2-table` when the rows are flat and
[`c2-group-table`](/web-components/components/group-table) to gather flat rows into groups.

## Import

```typescript tag=CodeBlock
import '@c2n/components/table/tree-table'
```

The entry registers `c2-tree-table`, `c2-table`, `c2-table-column`, and the checkbox and spinner they render.

## Usage

Give `children-field` the field holding each row's children, and the rows a `row-key`. A column with `rollup` shows in
a parent row the aggregate of the leaves under it.

```html tag=UsageBlock,package=@c2n/table
<style>
  .grid {
    height: 208px;
    width: 100%;
  }
</style>
<div data-label="Tree">
  <c2-tree-table client:only="lit" class="grid" row-key="id" children-field="children" expanded-rows="eng" selection="multiple" checkbox-selection rows='[{"id":"eng","name":"Engineering","children":[{"id":"web","name":"Web platform","headcount":14,"budget":1820000},{"id":"mobile","name":"Mobile","headcount":9,"budget":1160000}]},{"id":"design","name":"Design","children":[{"id":"brand","name":"Brand","headcount":4,"budget":420000},{"id":"product-design","name":"Product design","headcount":7,"budget":810000}]},{"id":"ops","name":"Operations","headcount":5,"budget":390000}]'>
    <c2-table-column field="name" header="Team" width="2fr" min-width="160" summary-label="Total"></c2-table-column>
    <c2-table-column field="headcount" header="People" width="90px" align="end" format="number" rollup="sum" summary="sum"></c2-table-column>
    <c2-table-column field="budget" header="Budget" width="130px" align="end" format="currency" rollup="sum" summary="sum"></c2-table-column>
  </c2-tree-table>
</div>
```

`children-field` names the field that holds each row's child rows, nested to any depth, and the grid becomes a
`treegrid`: a parent is an ordinary row with a chevron, and the first column (or the one marked `group-column`)
indents each level. Rows start closed; `tree-expanded` opens them all, and `expanded-rows` lists the open ones by key
(`;`-separated in the attribute; the first click writes the whole list into `expandedRows`). A click on the chevron,
←/→ on the tree column, `expandRow(key)`, `collapseRow(key)`, `expandAll()` and `collapseAll()` open and close them,
and `row-toggle` reports a click.

```html tag=CodeBlock
<c2-tree-table row-key="id" children-field="children" selection="multiple" checkbox-selection rows="...">
  <c2-table-column field="name" header="Account" summary-label="Total"></c2-table-column>
  <c2-table-column field="amount" header="Amount" align="end" format="currency" rollup="sum" summary="sum"></c2-table-column>
</c2-tree-table>
```

A column with `rollup` (`sum`, `avg`, `min`, `max`, `count`, or a function of the rows from script) shows in a parent
row the aggregate of the leaf rows under it, and a sort on that column orders each level by those figures. Sorting
keeps the tree: rows are ordered among their siblings. The summary row adds up the leaves, so every amount counts
once. With `selection="multiple"` a row is selected together with the rows under it, a parent is selected once all
its children are, and its checkbox shows the mixed state in between; the selection still holds row keys only.

A row whose field holds `true` is a parent whose children are not loaded yet. The first time it opens the table asks
`loadChildren` for them and shows a spinner in place of the chevron; a rejection closes the row again and fires
`children-error`, and the next open asks again. Lazy children are cached by key, so give the rows a `row-key`.

```typescript tag=CodeBlock
table.loadChildren = async ({ key }) => (await fetch(`/api/accounts/${key}/children`)).json()
```

The tree is built on the client; with a `dataSource` it is ignored, with a console warning.
The chevron is the `row-toggle` part and takes the `--c2-table__group-toggle--*` and `--c2-table__group--indent`
variables.
