`c2-badge` labels a state in a small tinted pill. Six `tone`s carry meaning (neutral, primary, success, warning, danger, info) and each is a background/text variable pair, so a design system recolours them without touching markup. Give it a `count` to show a number clamped at `max` (`99+`), or `dot` for a presence indicator that can `pulse`. Put an element in the `anchor` slot and the badge pins itself to one of its corners chosen with `placement`, the classic notification count on an icon button. `--c2-badge--background` and `--c2-badge--color` override whichever tone is active.

## Installation

```bash tag=CodeBlock
npm install @c2n/badge
```

A badge is static text: it has no focus or click behaviour. When it conveys something not visible elsewhere, give the host an `aria-label` (a `dot` badge in particular carries no text). A `count` of `0` renders nothing unless `show-zero` is set, so a notification badge can stay in the markup and simply disappear.

The anchored badge is positioned relative to the `c2-badge` host, which wraps the anchor as an inline-flex box. By default it sits on the corner of the anchor's bounding box, which suits buttons and cards; for a round anchor such as an avatar or icon button add `overlap="circular"` so the badge lands on the edge of the circle. `--c2-badge__anchor--border` draws the ring in your page background colour; set it to `none` on dark surfaces or when the badge sits on a card. The `__anchor--offset-*` variables fine-tune the position in either mode.
