# @c2n/week-planner

`c2-week-planner`: a typical week at a glance, seven day columns on an hour scale with optional odd and even weeks. Its
sibling for dated plans over a month is `@c2n/components/month-planner`.

```bash
npm install @c2n/components
```

```html
<script type="module">
  import '@c2n/components/week-planner'
</script>

<c2-week-planner events='[{"title":"Stand-up","day":"mon","start":"08:30","end":"09:00"}]'></c2-week-planner>
```

Documentation: https://code2nguyen.github.io/web-components/components/week-planner
