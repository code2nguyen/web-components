## Presets

Banded scales for lab results, pay bands and screening scores. The band `tone`s carry the meaning, the track
height and radius set the shape, and the three rows (value, band labels, numbers) can each be hidden through their
`display` variable.

<GalleryGrid columns="2">


The French card's numbers follow its `lang` ("3,5", "5,2"), and so does the text the indicator announces, once the
application supplies it:

```ts tag=CodeBlock
import { addTranslations } from '@c2n/core/localize.js'

addTranslations({ fr: { 'range-indicator': { label: 'Plage', valueInBand: '{0}, {1}' } } })
```
