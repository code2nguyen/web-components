# Feather Icons

`@c2n/feather-icons` wraps every [Feather](https://feathericons.com/) icon as its own web component: `c2-feather-<icon-name>`.
The components are generated from the `feather-icons` npm package, so the set tracks upstream releases.

## Installation

```bash tag=CodeBlock
npm install @c2n/feather-icons
```

## Import

Import individual icons to keep bundles small:

```typescript tag=CodeBlock
import '@c2n/feather-icons/icons/arrow-right.js'
import '@c2n/feather-icons/icons/camera.js'
```

or register the whole set at once:

```typescript tag=CodeBlock
import '@c2n/feather-icons'
```

## Examples

```html tag=MdxCodeBlock,compact=true
<c2-feather-arrow-right></c2-feather-arrow-right>
<c2-feather-camera></c2-feather-camera>
<c2-feather-heart></c2-feather-heart>
<c2-feather-settings></c2-feather-settings>
```

Icons inherit `currentColor` and are themed with the shared `--c2-feather-icon--*` custom properties.

```html tag=MdxCodeBlock,compact=true
<c2-feather-heart style="--c2-feather-icon--size: 48px; --c2-feather-icon--color: #dc2626"></c2-feather-heart>
<c2-feather-heart style="--c2-feather-icon--size: 48px; --c2-feather-icon--stroke-width: 1"></c2-feather-heart>
<c2-feather-heart style="--c2-feather-icon--size: 48px; --c2-feather-icon--stroke-width: 3"></c2-feather-heart>
```
