## Custom icons

Use the `icon` slot for an inline SVG or an icon component. `--c2-toast__icon--size` controls the icon area and the size of Feather and Material icon components; the icon inherits the toast's icon colour.

<GalleryGrid>

```html tag=MdxCodeBlock,label=Custom SVG
<style>
  .celebration {
    width: 340px;
    --c2-toast__container--background: #faf5ff;
    --c2-toast__container--border: 1px solid #e9d5ff;
    --c2-toast__container--color: #581c87;
    --c2-toast__icon--color: #9333ea;
    --c2-toast__icon--size: 26px;
  }
</style>
<c2-toast class="celebration" heading="A little milestone" message="You completed your first project.">
  <svg slot="icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.7" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true">
    <path d="m12 3 2.6 5.3 5.9.9-4.3 4.2 1 5.9-5.2-2.8-5.2 2.8 1-5.9-4.3-4.2 5.9-.9Z"></path>
  </svg>
</c2-toast>
```

## Without icons

Set `no-icon` to remove the leading icon and its spacing. Managed notifications accept the equivalent `noIcon: true` option. Action buttons here emit `toast-action`; connect that event to your application's behavior.

<GalleryGrid>

  .text-only {
    width: 300px;
    --c2-toast__container--box-shadow: none;

  }
</style>
<c2-toast class="text-only" no-icon message="Your preferences have been updated."></c2-toast>
