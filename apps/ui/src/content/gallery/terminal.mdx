## Presets

A terminal is dark in both themes, as one reads as a terminal. Its colours are all variables: `--c2-terminal--background-color` and `--c2-terminal--color` set the screen, `--c2-terminal__prompt--color` the prompt and caret, and the eight `--c2-terminal__ansi-*--color` variables the colours CLI output carries.
