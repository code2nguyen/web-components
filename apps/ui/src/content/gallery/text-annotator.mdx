The label bar, the list and the scores are the application's. A button applies its label to the selection with `annotate()`, the list is redrawn from `ranges` on `ranges-change`, and `renderTag` draws each tag from its range, which keeps any field the application stored on it:

```ts tag=CodeBlock
import type { TextAnnotator } from '@c2n/components/highlight/text-annotator'

const annotator = document.querySelector<TextAnnotator>('c2-text-annotator')!
const bar = document.querySelector('.label-bar')!

// Pressing a button must not move focus, which would clear the selection it labels.
bar.addEventListener('mousedown', (event) => event.preventDefault())
bar.addEventListener('click', (event) => {
  const label = (event.target as HTMLElement).closest<HTMLElement>('[data-label]')?.dataset.label
  if (label) void annotator.annotate(label)
})

annotator.renderTag = ({ range, label }) => `${label?.label ?? range.label} ${(range as { score?: number }).score?.toFixed(2) ?? ''}`

annotator.addEventListener('ranges-change', ({ detail }) => {
  const text = annotator.textContent ?? ''
  const people = detail.filter((range) => range.label === 'person').map((range) => text.slice(range.start, range.end))
  console.log(people)
})
```
