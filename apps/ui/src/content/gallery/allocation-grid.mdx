"Loaded a page at a time" gets its people from a `dataSource` that answers after a short delay, standing in for the network. The table only holds the page it fetched, so the weeks come from `periods`.

```ts tag=CodeBlock
grid.dataSource = {
  async getRows({ start, count }) {
    const response = await fetch(`/api/allocations?start=${start}&count=${count}`)
    return response.json() // { rows: [{ id, name, capacity, allocations: { '2026-11-09': 32 } }], total }
  },
}
```
