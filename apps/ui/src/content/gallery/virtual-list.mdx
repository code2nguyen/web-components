## Presets

Curated looks for `c2-virtual-list`. Open any card in the studio to start from it. `--c2-virtual-list__item--height`
and the border and radius group shape the box; the search-field variables theme the composed `c2-text-field`; and
everything inside a row — padding, type, hover and selected colours, dividers — comes from `c2-list-item`'s own
variables. A run of adjacent selected rows squares the corners between them on its own.
