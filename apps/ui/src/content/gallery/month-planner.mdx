while its events scroll past (`--c2-month-planner__agenda--max-height`). The header pages between months as on the

## Change calendar

An event with `display: 'background'` is drawn as a shaded band behind the days it covers: a change freeze, a
maintenance window, a public holiday. Its `color` is the shade itself, so give it a translucent one. Changes stay bars
in their own lanes over the bands. The planner does not compare them: the app flags a change that lands in a freeze,
here with a red bar and a title that says so.

`renderAgendaEvent` draws the content of each listed event. The planner keeps the item, a button named after the
event's title and dates that fires `event-click`, and calls the renderer once for each day the event is listed under:

```ts tag=CodeBlock
import { html } from 'lit'
import type { MonthPlannerAgendaEventContext } from '@c2n/components/month-planner'

const days = (from: string, to: string) => Math.round((Date.parse(to) - Date.parse(from)) / 86_400_000)

planner.view = 'agenda'
planner.renderAgendaEvent = ({ event, date, start, end, background }: MonthPlannerAgendaEventContext) => {
  const length = days(start, end) + 1
  return html`<span part="change-kind">${background ? 'Window' : 'Change'}</span>
    <span part="change-title">${event.title}</span>
    ${length > 1 ? html`<span part="change-progress">Day ${days(start, date) + 1} of ${length}</span>` : ''}`
}
```
