## Presets

Each treatment changes only the public CSS variables. The field's `background`, `border` and `border-radius` set its look, and the `__picker*` and `__day*` variables restyle the popup.

<GalleryGrid columns="2">

```html tag=MdxCodeBlock,label=Default
<style>
  .default {
    width: 100%;
    max-width: 280px;
  }
</style>
<c2-date-time-picker class="default" aria-label="Meeting" value="2026-10-14T09:30"></c2-date-time-picker>
```

```html tag=MdxCodeBlock,label=Soft
<style>
  .soft {
    width: 100%;
    max-width: 280px;
    --c2-date-time-picker--background: var(--c2-theme--color-surface-container, #f4f4f5);
    --c2-date-time-picker--border: 1px solid transparent;
    --c2-date-time-picker__hover--border: 1px solid var(--c2-theme--color-outline, #d4d4d8);
    --c2-date-time-picker--border-radius: 10px;
    --c2-date-time-picker__picker--border-radius: 14px;
    --c2-date-time-picker__day--border-radius: 8px;
  }
</style>
<c2-date-time-picker class="soft" aria-label="Reminder" value="2026-10-14T09:00"></c2-date-time-picker>
```
