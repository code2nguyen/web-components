## Rows

Padding, radius and the hover / selected colours are all `--c2-list-item--*` variables. Put the class on each row, or on a wrapper: custom properties inherit.

## Icons and content

`prefix-icon` and `suffix-icon` accept an inline SVG, a `c2-feather-*` icon or a `c2-mat-icon`, sized by `--c2-list-item__icon--size`. Anything can go in the default slot; use `label` to give a select a short name for a rich row.
