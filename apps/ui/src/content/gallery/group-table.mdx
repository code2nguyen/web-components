`c2-group-table` is `c2-table` with groups. Every card of the table gallery works here too; these are the ones that need the rows grouped. Nested rows are on the [tree table](/web-components/components/tree-table/gallery) page.

## Grouping

`group-by` gathers the rows into collapsible groups, outermost level first: `group-by="region,status"` nests the statuses of each region. By default each group is a row of the grid — its label and row count in the first column, and under every column with a `summary` that figure for the group's rows, so subtotals line up with the totals row. `group-display="band"` draws a full-width band per group instead. The groups of the rows at the top of the view stay under the header while they scroll, a group's checkbox selects its rows, and `groups-collapsed` starts them closed. The table does not ship a "group by" picker: the last card builds one from a `c2-button-group` in the `toolbar` slot that sets `groupBy`.
