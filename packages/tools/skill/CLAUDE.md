# @c2n/skill

Guidance for `packages/tools/skill`. Claude Code loads this file when it works in this directory; the repo-wide rules are in the root `CLAUDE.md`. Paths are relative to the repository root.

`packages/tools/skill` — published `@c2n/skill`, a portable skill/plugin for Claude Code, Codex, Google Antigravity and GitHub Copilot (`c2n-skill install --agent copilot` writes `.github/skills/`, `.vscode/mcp.json` with its `servers` key, and a marker-delimited block in `.github/copilot-instructions.md`; `--mcp local|npx|auto` chooses between the project's `node_modules/@c2n/mcp` and an `npx` download, auto preferring the local copy because `npx` fails silently behind a proxy). `skills/c2n-components/SKILL.md` and the workflow/theming/variant/framework references are hand-written; `references/component-catalog.md` is a compact discovery-only index generated from the MCP registry by `scripts/build-skill.ts`. Exact API facts come from MCP or an installed package's `custom-elements.json`, not the catalog. The build script also synchronizes portable/Claude plugin manifests and the matching `@c2n/mcp` version. The repo dogfoods the skill through project-scoped agent directories. Neither tools package is in the root `wireit.build` list (the MCP registry depends on the root build group, so that would be a cycle): they build through `pnpm run build:tools`.
