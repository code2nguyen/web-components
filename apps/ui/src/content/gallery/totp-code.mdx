The property card sets the secret from script, so it never appears in the markup, and logs each new code:

```ts tag=CodeBlock
const code = document.querySelector('c2-totp-code')!
code.secret = await vault.totpSecret(accountId)
code.addEventListener('code-change', () => (output.textContent = `code-change at ${new Date().toLocaleTimeString()}`))
```

The French card's labels come from the app's translations:

```ts tag=CodeBlock
import { addTranslations } from '@c2n/core/localize.js'

addTranslations({
  fr: {
    'totp-code': {
      show: 'Afficher le code',
      copy: 'Copier le code',
      copied: 'Copié',
      unavailable: 'Code indisponible',
      period: 'Nouveau code toutes les {0} secondes',
    },
  },
})
```
