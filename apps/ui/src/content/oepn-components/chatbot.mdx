# Chatbot

`c2-chatbot` provides a minimal support-chat shell. Application-owned conversation content goes in the default slot; use ordinary classes for those assigned messages and the public `messages` part for the component-owned conversation region.

## Installation

```bash tag=CodeBlock
npm install @c2n/chatbot
```

## Import

```typescript tag=CodeBlock
import '@c2n/chatbot'
```

## Examples

```html tag=MdxCodeBlock,compact=true,component=c2-chatbot
<style>
  .support-chat {
    width: 22rem;
  }
  .support-chat::part(messages) {
    padding: 1rem;
    background: #eff6ff;
  }
  .support-chat .customer-message {
    margin: 0;
    color: #1e3a8a;
  }
</style>
<c2-chatbot class="support-chat" client:only="lit">
  <p class="customer-message">Hi! How can we help?</p>
</c2-chatbot>
```
