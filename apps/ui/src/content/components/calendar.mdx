`c2-calendar` shows a plan on a month grid. Each entry in `events` is drawn as a bar from its `start` to its `end`
day, so a vacation reads as one strip with a clear beginning and end, continued on the next row when it crosses a
week. Overlapping entries stack in separate lanes. The header steps between months (and back to today); `month`
picks the one shown, `week-start` and `locale` match the audience.

To jump further, click the month title: a picker shows the twelve months of a year with a year stepper above them. A
dot and a soft tint mark every month that has events, so a plan months away is two or three clicks. Arrow keys move between months, Page Up and Page Down change the year,
Enter picks and Escape closes. Set `month-picker="false"` for a plain title.

## Installation

```bash tag=CodeBlock
npm install @c2n/calendar
```

## Usage

```html tag=UsageBlock,package=@c2n/calendar
<div data-label="Vacation plan">
  <c2-calendar
    month="2026-09"
    locale="en-US"
    events='[{"id":"vacation","title":"Vacation in Lisbon","start":"2026-09-10","end":"2026-09-18","color":"#0f766e"},{"id":"flight","title":"Flight TP 1235","start":"2026-09-10","color":"#b45309"},{"id":"summit","title":"Web Summit","start":"2026-09-01","end":"2026-09-03"},{"id":"review","title":"Quarterly review","start":"2026-09-24"}]'
  ></c2-calendar>
</div>
```

## Events

Each entry is `{ id?, title, start, end?, color? }`. Dates are local `YYYY-MM-DD` strings and `end` is inclusive;
leave it out for a one-day entry. `color` is any CSS colour for that bar (pick one that keeps white text readable),
otherwise `--c2-calendar__event--background` applies. Entries without a valid `start` are skipped.

Set `events` as a property from code, or as a JSON attribute in markup. Bars are buttons: clicking one (or pressing
Enter on it) fires `event-click` with the entry in `event.detail.event`. The header fires `month-change` with the
month now shown (`YYYY-MM`), which is where to load the next month's plan.

```ts tag=CodeBlock
import '@c2n/calendar'

const calendar = document.querySelector('c2-calendar')!
calendar.events = [{ id: 'trip', title: 'Vacation', start: '2026-09-10', end: '2026-09-18' }]
calendar.addEventListener('event-click', (event) => console.log(event.detail.event.id))
calendar.addEventListener('month-change', (event) => console.log(event.detail.month))
```
