## Saved views

`views` turns the panel into a view switcher: a select of the user's views and the shared ones, "Modified" while the value has moved from the current view, and Save, Save as…, Rename and Delete. The component saves nothing: it fires `view-save`, `view-rename` and `view-delete`, and these cards keep the views in memory the way an app would keep them on its server. A locked view (the shared "Team backlog") can be copied with Save as, not changed.

options.addEventListener('view-save', async ({ detail }) => {
