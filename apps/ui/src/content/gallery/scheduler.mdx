## Find a time

The attendees are the resources and their bookings read-only events (`pending` ones are tentative). `proposal` draws
the meeting being planned as a block in the header and a column on every row: red where an attendee is busy, amber
where they are only tentative, green where they are free. Drag the block or its column where a row is free, or
focus the block and use the arrow keys; `proposal-change` reports who is busy at the new time, checked on drop, and
the page moves the proposal there. Across time zones, per-resource `bands` shade each attendee's evening and night in the scheduler's
own zone; they are drawn, not checked.

```ts tag=CodeBlock
import { html } from 'lit'
import type { Scheduler } from '@c2n/components/scheduler'

const scheduler = document.querySelector<Scheduler>('c2-scheduler')!
// Called once per column (a day here) with the absences over it and every resource.
scheduler.renderSummary = ({ events, resources }) => {
  const out = new Set(events.map((event) => event.resource)).size
  if (!out) return ''
  const short = resources.length - out < 4
  return html`<span part=${short ? 'out short' : 'out'}>${out}</span>`
}
```

```ts tag=CodeBlock
// Find a time: the page owns the proposal and moves it where the user dropped it.
scheduler.proposal = { start: '2026-11-09T10:00', end: '2026-11-09T11:00', title: 'Design review' }
scheduler.addEventListener('proposal-change', ({ detail }) => {
  scheduler.proposal = { ...scheduler.proposal, start: detail.start, end: detail.end }
  console.log('busy', detail.busy, 'tentative', detail.tentative)
})

// "Next free time": the first hour after the proposal when no attendee has a booking.
nextFree.addEventListener('click', () => {
  const slot = scheduler.findFreeTime(60, scheduler.proposal!.end)
  if (!slot) return
  scheduler.proposal = { ...scheduler.proposal, ...slot }
  scheduler.scrollTime = slot.start.slice(11) // brings it on screen
})

// How many are free, in the block and in a row under the grid.
scheduler.renderProposal = ({ title, busy, resources }) => html`${title} <span part="count">${resources.length - busy.length}/${resources.length} free</span>`
scheduler.renderSummary = ({ events, resources }) => {
  const busy = new Set(events.filter((event) => !event.pending).map((event) => event.resource)).size
  return html`<span part="free">${resources.length - busy}/${resources.length}</span>`
}
```
