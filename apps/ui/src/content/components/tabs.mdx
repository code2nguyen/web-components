`c2-tabs` pairs a row of `c2-tab` headers with content panels. Every `<c2-tab for="…">` child becomes a tab; every other child is a panel and is shown when its `id` matches the tab's `for`. Set the initial tab with `selected-tab`, or leave it out to start on the first enabled tab. The strip is a proper `tablist`: Left/Right arrows, Home and End move between tabs (disabled tabs are skipped), Enter and Space activate. Tab labels are slotted content, so an icon component (`c2-feather-*`, `c2-mat-icon`) or an inline SVG can sit next to, or instead of, the text; give icon-only tabs an `aria-label`. It fires `change` (`detail.value`) after a user picks a tab; listen for the cancelable `tab-change` from a `c2-tab` and call `preventDefault()` to veto a switch.

When there are more tabs than room (six tabs on a phone), set `overflow="scroll"`: the tab list scrolls sideways instead of running past the page, the selected tab is scrolled into view whenever it changes, the arrow keys still reach every tab, and an edge with hidden tabs fades out (`--c2-tabs__fade--width`). The scrollbar is hidden; set `--c2-tabs--scrollbar-width: thin` to show one for mouse users without a horizontal wheel.

Or set `overflow="menu"` to fold instead of scroll: the tabs that do not fit, from the end, go into a "More" menu after the strip, and the selected tab never folds. Picking a tab from the menu selects it (through the same cancelable `tab-change` as a click) and brings it back into the strip in place of another, and the arrow keys, Home and End move onto folded tabs the same way. Restyle the trigger through `--c2-tabs__more--*` or its `more` part.

Strips that share a `sync-key` switch together, which is how a page of install commands keeps one package-manager (or language) switcher: picking `pnpm` in one strip selects the tab labelled `pnpm` in every other strip with that key, and the choice is remembered in `localStorage` (`c2n-tabs:<sync-key>`) so the page opens on it next time. Tabs are matched by their label, so the panel ids stay unique per strip. For tabs that are links between pages, use [`c2-tab-nav`](/web-components/components/tab-nav).

## Import

```typescript tag=CodeBlock
import '@c2n/components/tabs'
```

The examples use icons from the separate `@c2n/feather-icons` package: `npm install @c2n/feather-icons`. The `c2-mat-icon` examples also need a Material icon font, which `c2-mat-icon` does not load: `npm install @fontsource/material-icons`, then `import '@fontsource/material-icons'`.

## Usage

```html tag=UsageBlock,package=@c2n/tabs
<style>
  .code-tabs {
    display: grid;
    gap: 12px;
    width: 100%;
    max-width: 380px;
  }
</style>
<div data-label="Default">
  <c2-tabs client:only="lit" selected-tab="tab2">
    <c2-tab label="Tab 1" for="tab1"></c2-tab>
    <c2-tab for="tab2">Tab 2</c2-tab>
    <c2-tab for="tab3" disabled>Tab 3</c2-tab>
    <c2-tab for="tab4">Tab 4</c2-tab>
    <div id="tab1">Tab 1 content</div>
    <div id="tab2">Tab 2 content</div>
    <div id="tab3">Tab 3 content</div>
    <div id="tab4">Tab 4 content</div>
  </c2-tabs>
</div>
<div data-label="Icon and label">
  <c2-tabs client:load selected-tab="inbox" style="--c2-tabs--gap: 4px; --c2-feather-icon--size: 16px">
    <c2-tab for="inbox"><c2-feather-inbox></c2-feather-inbox>Inbox</c2-tab>
    <c2-tab for="starred"><c2-feather-star></c2-feather-star>Starred</c2-tab>
    <c2-tab for="archive"><c2-feather-archive></c2-feather-archive>Archive</c2-tab>
    <div id="inbox">Inbox panel</div>
    <div id="starred">Starred panel</div>
    <div id="archive">Archive panel</div>
  </c2-tabs>
</div>
<div data-label="Synced code tabs">
  <div class="code-tabs">
    <c2-tabs client:load sync-key="docs-pm" aria-label="Install">
      <c2-tab for="install-npm">npm</c2-tab>
      <c2-tab for="install-pnpm">pnpm</c2-tab>
      <c2-tab for="install-yarn">yarn</c2-tab>
      <div id="install-npm"><c2-code-viewer language="bash" theme="github-light" dark-theme="github-dark-default" copyable code="npm install @c2n/components"></c2-code-viewer></div>
      <div id="install-pnpm"><c2-code-viewer language="bash" theme="github-light" dark-theme="github-dark-default" copyable code="pnpm add @c2n/components"></c2-code-viewer></div>
      <div id="install-yarn"><c2-code-viewer language="bash" theme="github-light" dark-theme="github-dark-default" copyable code="yarn add @c2n/components"></c2-code-viewer></div>
    </c2-tabs>
    <c2-tabs client:load sync-key="docs-pm" aria-label="Run">
      <c2-tab for="run-npm">npm</c2-tab>
      <c2-tab for="run-pnpm">pnpm</c2-tab>
      <c2-tab for="run-yarn">yarn</c2-tab>
      <div id="run-npm"><c2-code-viewer language="bash" theme="github-light" dark-theme="github-dark-default" copyable code="npx c2n-skill install"></c2-code-viewer></div>
      <div id="run-pnpm"><c2-code-viewer language="bash" theme="github-light" dark-theme="github-dark-default" copyable code="pnpm dlx c2n-skill install"></c2-code-viewer></div>
      <div id="run-yarn"><c2-code-viewer language="bash" theme="github-light" dark-theme="github-dark-default" copyable code="yarn dlx c2n-skill install"></c2-code-viewer></div>
    </c2-tabs>
  </div>
</div>
<div data-label="Icon only">

    <c2-tab for="chart" aria-label="Analytics"><c2-feather-pie-chart></c2-feather-pie-chart></c2-tab>
```
