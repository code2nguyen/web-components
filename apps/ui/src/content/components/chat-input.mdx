`c2-chat-input` grows with its message until it reaches the configured maximum height. Enter fires `submit-message`; Shift+Enter or Alt+Enter inserts a newline. Empty messages are ignored, and canceling the event keeps the draft in place. The component also participates in forms through `name`, validation constraints, fieldset disabling and form reset.

Set `enter-behavior="newline"` when the composer should reserve Enter for multiline writing; users can still send with the button.

## Installation

```bash tag=CodeBlock
npm install @c2n/chat-input
```

Listen for `submit-message` to send the value. Call `preventDefault()` when a send fails or requires confirmation—the current draft will remain in the composer.

```js tag=CodeBlock
const composer = document.querySelector('c2-chat-input')

composer.addEventListener('submit-message', async (event) => {
  await sendMessage(event.detail)
})
```
