## Presets

The box is one set of variables (`--c2-phone-input--border`, `--c2-phone-input--background`, `--c2-phone-input--border-radius`, `--c2-phone-input--min-height`) with `__hover--*`, `__focus--*` and `__invalid--border` on top. The `--c2-phone-input__country--*` variables style the country button and `__divider--border` the line after it; `__flag--display: none` leaves only the calling code, and `__country--display: none` hides the button altogether (with a single country in `countries`). The `__panel--*`, `__search--*` and `__option--*` variables style the country list.

## Language

<PhoneInputExamplesRuntime />

The field and country names, the country search and the validation messages are message tokens: an app translates them once with `addTranslations`, and each input speaks the language of its nearest `lang`. The country names come from `Intl.DisplayNames` in the `locale` attribute.

<GalleryGrid columns="2">

```html tag=MdxCodeBlock,label=En français,description=The country list and its search in the language of the page,useWhen=The application is translated
<div lang="fr">
  <c2-phone-input client:only="lit" country="FR" locale="fr" required></c2-phone-input>
</div>
```

</GalleryGrid>

```ts tag=CodeBlock
import { addTranslations } from '@c2n/core/localize.js'

addTranslations({
  fr: {
    'phone-input': {
      label: 'Numéro de téléphone',
      country: 'Pays : {0} (+{1})',
      valueMissing: 'Saisissez un numéro de téléphone.',
      patternMismatch: 'Saisissez un numéro de téléphone valide pour {0}.',
      search: 'Chercher un pays',
      empty: 'Aucun pays trouvé',
    },
  },
})
```
