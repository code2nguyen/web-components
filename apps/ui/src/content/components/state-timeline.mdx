`c2-state-timeline` shows how a set of things changed state over time, one band per thing: which services were
degraded during an incident, which branches failed their builds, when hosts slept. Set `series` to an array (or a JSON
attribute) of bands, each a `label` and a list of segments with a `start`, an optional `end` and a `state`. A segment
without an `end` lasts until the next one starts, so a log of state changes is enough; the last one runs to the end of
the timeline. `states` names the values and picks their colours with a `tone` (`success`, `warning`, `danger`,
`primary`, `neutral`, or a chart palette slot `1` to `8`); values it does not list are shown as written, each with the
next free palette colour. A `null` state marks a stretch with no data. The visible range is `start`–`end`, or the span
of the data, and times are shown in the reader's time zone. Hover or focus a segment for its times and duration; the
timeline is one Tab stop, the arrow keys move between segments and bands, and Enter fires `segment-click`.

## Import

