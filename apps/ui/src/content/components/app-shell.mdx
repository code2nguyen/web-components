`c2-app-shell` lays out a whole application: a `banner` strip, the `header` (usually a `c2-header`), a `navigation` with its own `navigation-header` and `navigation-footer`, the main content in the default slot, an `aside` details panel and a `footer`. Each region is rendered in its own landmark, and a skip link to main comes first in the tab order.

The layout follows the shell's **own width**, not the window's, so each frame below behaves like the device its width matches: the docs column is tablet-sized, so the first frame sets `tablet-mode="side"` to show a side navigation. Below 600px the navigation is a modal drawer (`over`); `tablet-mode` (600 to 959px, `rail` by default) and `desktop-mode` (960px and up, `side` by default) choose between `side`, which pushes main, `rail`, which collapses to its icons, and `over`. The aside is a column from 960px and a sheet from the end edge below. Put a `c2-app-shell-toggle` anywhere inside the shell, including in the slotted `c2-header`, to open and close the navigation; `for="aside"` does the same for the aside. A drawer traps focus, closes on Escape and on a click outside, and gives focus back to the toggle; with `close-on-navigate` a link in the drawer closes it too.

`layout="navigation-first"` runs the navigation the full height with the header beside it, the arrangement of Linear or Stripe. Hide item labels in a collapsed rail with `c2-app-shell:state(rail):not(:state(navigation-opened)) .label { display: none }`. When the page scrolls (default) the header sticks; `scrolling="main"` gives the shell `--c2-app-shell--height` and scrolls only main. Either way `--c2-app-shell--sticky-offset` tells sticky content such as a `c2-page-header` where the header ends.

## Import

```typescript tag=CodeBlock
import '@c2n/components/app-shell'
```

The examples use icons from the separate `@c2n/feather-icons` package: `npm install @c2n/feather-icons`.

## Usage

The frames are fixed-size containers with `scrolling="main"` and `--c2-app-shell__over--position: absolute`, so the drawer stays inside them; in an app the shell fills the page and the drawer covers the viewport.
