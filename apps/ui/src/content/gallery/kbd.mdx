## Presets

Curated looks for `c2-kbd`. Open any card in the studio to start from it. A keycap is mostly four variables — `--c2-kbd--background-color`, `--c2-kbd--border`, `--c2-kbd--border-radius` and `--c2-kbd--box-shadow` — and the default is a flat, light tag: adding a shadow is what turns it into a raised key.

<GalleryGrid>

```html tag=MdxCodeBlock,label=Default
<c2-kbd>⌘ + K</c2-kbd>
```

```html tag=MdxCodeBlock,label=Raised
<style>
  .raised {
    --c2-kbd--background-color: var(--c2-theme--color-surface-container, #f4f4f5);
```
