`c2-chat-message-list` is the scrolling part of a chat room: put `c2-chat-message` rows inside it and a `c2-chat-input` below it, and you have a chatbot. It is an accessible `log` region that stays pinned to the latest message while the reader is at the bottom — including a reply that grows while it streams. Once the reader scrolls up, it keeps their place, and a floating button jumps back with a count of the messages that arrived in the meantime. Set `has-more` and it fires `load-older` when the reader reaches the top; set `loading` while the history request runs, then prepend the older rows and the view does not move.

Give the list a height (or let it fill a flex column); it scrolls its own content. The application owns the messages: append, prepend or update the children and the list reacts. Call `scrollToBottom()` after the user sends a message so their own message is always shown.

## Installation

```bash tag=CodeBlock
npm install @c2n/chat-message-list @c2n/chat-message @c2n/chat-input
```
