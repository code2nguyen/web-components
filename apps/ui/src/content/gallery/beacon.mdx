## Presets

Curated looks for `c2-beacon`. Click a dot to open its tip. The dot is styled through `--c2-beacon__dot--*` (`size`, `color`, `border-color`, `translate`) and its pulse through `--c2-beacon__pulse--*`; the tip is the tour's panel, so `--c2-tour--*` styles it. `--c2-beacon__backdrop--color` dims the page around an open tip.

The Remembered card's button forgets the dismissed tips; the French card's text is the translation an app adds:

```ts tag=CodeBlock
import { addTranslations } from '@c2n/core/localize.js'

addTranslations({ fr: { tour: { dismiss: 'Compris', beacon: 'Voir l’astuce : {0}', beaconUnnamed: 'Voir l’astuce', close: 'Fermer' } } })

resetButton.addEventListener('click', () => document.querySelector('c2-beacon')!.reset())
```
