## Presets

Curated looks for `c2-copy-button`. Open any card in the studio to start from it. Everything hangs off `__container--*` for the button box and `__icon--*` for the glyph, with a `__container__copied--*` set for the moment after the copy lands. Every card here sets `reveal="always"`, because nothing hovers a gallery card — in a real page the default hides the button until its source is hovered.
