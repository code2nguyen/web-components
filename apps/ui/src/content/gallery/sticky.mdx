## Sticky call to action

`show-when-hidden` takes the id of the element the bar stands in for. The bar is hidden while that element is on screen and slides in once it is scrolled out of view. The last card watches its element by reference instead, which also reaches an element in another shadow root or one rendered later:

```ts tag=CodeBlock
const bar = document.querySelector('c2-sticky')!
bar.showWhenHiddenElement = document.querySelector('#pricing-cta')
bar.addEventListener('conceal-change', (event) => {
  console.log(event.detail.concealed ? 'main button on screen' : 'bar shown')
})
```

`c2-sticky` draws no text of its own, so the French card is translated by its author alone.
