## Presets

Curated looks for `c2-delta`. Open any card in the studio to start from it. The change inherits the surrounding text, so size and weight come from the page; the good, bad and flat colours read the direction, and the comparison label stays quieter than the number.

The arrow's accessible name is a message of the component; an app names it in its own languages:

```ts tag=CodeBlock
import { addTranslations } from '@c2n/core/localize.js'

addTranslations({
  fr: {
    'format-number': {
      increaseBetter: 'Hausse, mieux',
      increaseWorse: 'Hausse, pire',
      decreaseBetter: 'Baisse, mieux',
      decreaseWorse: 'Baisse, pire',
    },
  },
})
```
