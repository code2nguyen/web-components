`c2-color-slider` allows users to select hue of a color from 0 to 360.

## Installation

```bash tag=CodeBlock
npm install @c2n/color-slider
```

## Usage

```html tag=UsageBlock,package=@c2n/color-slider
<div data-label="Default">
  <c2-color-slider></c2-color-slider>
</div>
```
