`c2-spinner` is a ring that spins while something is in flight. Give it a `value` (out of `max`, 100 by default) and it turns into a determinate ring that fills clockwise and animates between values. Text in the default slot sits beside the ring and doubles as its accessible name; without text, `label` (or "Loading") names it. It is a `progressbar` for assistive technology, with `aria-valuenow` when determinate. Size, stroke, colours and speed are variables, and the reduced-motion setting replaces the pulsing arc with a slow, steady turn.

## Installation

```bash tag=CodeBlock
npm install @c2n/spinner
```

```html tag=UsageBlock,package=@c2n/spinner
  <c2-spinner></c2-spinner>

</div>
<div data-label="Colours">
  <c2-spinner class="success" value="80"></c2-spinner>
  <c2-spinner style="--c2-spinner--color: #dc2626; --c2-spinner__track--color: #fee2e2"></c2-spinner>

  <c2-spinner style="--c2-spinner--flex-direction: column; --c2-spinner--size: 32px; --c2-spinner--gap: 10px">Preparing your export</c2-spinner>
</div>
<div data-label="In context">
  <div class="card">
    <strong>Deploying</strong>
    <c2-spinner value="60" style="--c2-spinner--size: 20px; --c2-spinner--stroke-width: 6px">Building assets (60%)</c2-spinner>
  </div>
  <c2-button running>Saving…</c2-button>
</div>
```

Use an indeterminate spinner when you cannot tell how long an operation takes, and a `value` when you can: set it as progress comes in and the arc animates to the new position. `value` is clamped to `0`–`max`, and clearing it returns the ring to the indeterminate spin.

Always give a spinner a name. Slotted text is announced and also shown; `label` names a bare ring without showing anything. For a page-level wait, put the spinner inside the region it describes rather than making a separate live region announce it. The `c2-button` component has its own `running` state that uses the same look for inline actions.

The ring is a 48-unit SVG box, so `--c2-spinner--stroke-width` scales with `--c2-spinner--size` (a `4px` stroke is 2px thick on a 24px spinner). `--c2-spinner--color` is the arc, `--c2-spinner__track--color` the ring behind it (set `transparent` for an arc alone), `--c2-spinner--animation-duration` the cycle time, and `--c2-spinner--flex-direction: column` moves the text under the ring.
