## Presets

A receivables report by customer, the same grouped by region, finer buckets for a collections team, payables aged from
the bill date, a compact heatmap, a drill-down into the invoices, a date input in the as-of slot and a French report.
The as-of line, the overdue tones and every pivot table variable are restyled through CSS variables.
