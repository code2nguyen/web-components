The value card reads `value` on every edit; it stays empty until the three parts make a real date:

```ts tag=CodeBlock
const birth = document.querySelector('c2-date-fields')!
birth.addEventListener('input', () => (output.textContent = `value: "${birth.value}"`))
```

The French card's labels and messages come from the app's translations:

```ts tag=CodeBlock
import { addTranslations } from '@c2n/core/localize.js'

addTranslations({
  fr: {
    'date-fields': {
      day: 'Jour',
      month: 'Mois',
      year: 'Année',
      min: 'La date doit être le {0} ou après',
      // …one entry per message
    },
  },
})
```
