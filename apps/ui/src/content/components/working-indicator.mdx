`c2-working-indicator` says that something is running right now, the way an agent shows "✻ Scheming… 12s". It is one line: an animated `indicator` (a cycling glyph, dots, a ring, a pulse or an orbit), a label that animates through its `effect` (`shimmer`, `wave`, `pulse` or `fill`), trailing dots from `ellipsis`, and an optional `elapsed` counter followed by the `meta` slot. Give it several `messages` and it rotates through them. When the work ends, set `state` to `done` or `error`: the animations stop, the indicator becomes a check or a cross, `done-label` replaces the text, and the line stays as a record. `paused` freezes the animations and the counter.

## Import

```typescript tag=CodeBlock
import '@c2n/components/working-indicator'
```

The element is a polite live region (`role="status"`, busy while running). It announces the `label` and the outcome only: the rotating `messages`, the wave's split letters and the counter are hidden from assistive technology, so a screen reader hears "Working" once and then "Schemed for 14s" rather than a new word every three seconds. With a `value` (out of `max`) it is a `progressbar` instead, and the `fill` effect fills the label to that fraction. Slotted label content replaces `label` and is exposed as written; the `wave` effect needs plain `label` text to split into letters.

Every timing is a variable: `--c2-working-indicator__indicator--animation-duration`, `__label--animation-duration`, `__label--stagger` for the wave, `__ellipsis--animation-duration`, and `__label--rotate-duration`, which sets how long each message stays on screen. The shimmer band, the wave crest and the filled part of the label all use `--c2-working-indicator__label--highlight-color`. Under `prefers-reduced-motion` every animation stops and the messages change without fading.

Set `started` (a millisecond timestamp) when the line is re-rendered mid-task, so the counter keeps measuring from the real start. Swap the built-in mark through the `indicator` slot, and the done/error marks through `done-icon` and `error-icon`.
