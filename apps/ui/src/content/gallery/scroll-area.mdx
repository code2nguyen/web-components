"Buttons in a header" puts the app's own buttons in its header and calls `scrollPage()`, which is what the built-in controls do:

```ts tag=CodeBlock
header.querySelectorAll('[data-scroll-page]').forEach((button) => button.addEventListener('click', () => area.scrollPage(button.dataset.scrollPage)))
```

"In French" sits under `lang="fr"`: the buttons' names come from the translation the page registered.

```ts tag=CodeBlock
import { addTranslations } from '@c2n/core/localize.js'

addTranslations({
  fr: { 'scroll-area': { label: 'Contenu défilant', top: 'Défiler vers le haut', bottom: 'Défiler vers le bas', start: 'Défiler vers l’arrière', end: 'Défiler vers l’avant' } },
})
```
