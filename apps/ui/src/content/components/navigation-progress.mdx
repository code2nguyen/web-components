`c2-navigation-progress` is the bar that runs across the top of a single-page application while the next route loads. `start()` shows it and trickles it forward in smaller and smaller steps, so it keeps moving without ever reaching the end; `done()` fills it and fades it out. Calling `start()` again while it fades begins a new run. For a framework that binds a "navigating" flag rather than calling methods, the `active` property is the same run: `true` starts it, `false` finishes it.

Put one on the page. It draws in the top layer, above dialogs, drawers and anything positioned, so a navigation started from a modal still shows. Add `contained` to draw it at the top of the nearest positioned ancestor instead: a panel, a card or a frame that loads on its own.

The trickle measures time, not work, so the bar is announced as a progress bar with a name ("Loading page", or `label`) and no value. Use [`c2-progress`](/web-components/components/progress) when you know how much is done.

## Import

```typescript tag=CodeBlock
import '@c2n/components/progress/navigation-progress'
```

The entry is separate from `@c2n/components/progress`, so importing it does not load `c2-progress`.

In an application the bar sits once in the page shell and the router drives it:

```ts tag=CodeBlock
import '@c2n/components/progress/navigation-progress'

const bar = document.querySelector('c2-navigation-progress')!
router.beforeEach(() => bar.start())
router.afterEach(() => bar.done())
```

`--c2-navigation-progress--height` and `--c2-navigation-progress__indicator--background-color` set the bar, `--c2-navigation-progress__indicator--box-shadow` adds a glow, `--c2-navigation-progress--animation-duration` paces the fade-in, each step and the final fill, and `--c2-navigation-progress--fade-duration` the fade-out. Under reduced motion the steps jump instead of sliding; the fades stay.
