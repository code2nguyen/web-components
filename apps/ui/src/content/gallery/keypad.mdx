## Presets

Looks for `c2-keypad`. The keys' shape and fill, and the size of the display, set the style.

```html tag=MdxCodeBlock,label=Passcode
<style>
  .keypad-passcode {
    /* Three 60px columns and two 10px gaps: each key is as wide as it is tall, so the radius draws a circle. */
    --c2-keypad--width: 200px;
    --c2-keypad__key--height: 60px;
    --c2-keypad__key--border-radius: 999px;
    --c2-keypad__key--font-size: 26px;
    --c2-keypad__key--font-weight: 400;
    --c2-keypad__keys--gap: 10px;
    --c2-keypad__dot--size: 12px;
  }
</style>
<c2-keypad class="keypad-passcode" display="pin" length="6" value="123"></c2-keypad>
```
