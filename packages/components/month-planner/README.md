# @c2n/month-planner

`c2-month-planner`: a month calendar that draws events and trips as bars across the days they cover. Its sibling for a
typical week is `@c2n/components/week-planner`.

```bash
npm install @c2n/components
```

```html
<script type="module">
  import '@c2n/components/month-planner'
</script>

<c2-month-planner events='[{"title":"Vacation","start":"2026-09-10","end":"2026-09-18"}]'></c2-month-planner>
```

Documentation: https://code2nguyen.github.io/web-components/components/month-planner
