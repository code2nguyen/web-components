## Presets

Curated looks for `c2-dashboard`. Open any card in the studio to start from it. Almost all the work is done by four
variables: `--c2-dashboard--background` with `--c2-dashboard--padding` turns the gutters into a frame,
`--c2-dash-card--background` and `--c2-dash-card--border` give a pane its surface, and
`--c2-dash-card__handle__hover--background` is the only colour the user sees while dragging. Drag any shared edge.

A real one: a `c2-list`, a `c2-line-chart` and a `c2-table`, one per pane. Each header carries its own controls —
a `c2-badge` and a `c2-icon-button` in `actions`, another `c2-icon-button` in `controls` so it sits next to the
built-in fullscreen button — and a `footer` under the content. `storage-key` keeps the sizes you drag.

A pane is bare on purpose: nothing above sets a single `--c2-*` variable, and every surface you see belongs to the
markup inside the panes. The cards below move that surface onto the component itself.
