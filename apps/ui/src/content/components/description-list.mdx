`c2-description-list` is the Descriptions of antd and the DescriptionList of Polaris: the block of label and value pairs at the top of an order, a customer or a deployment page. Each pair is a `c2-description-item` with a `label` attribute (or a `label` slot for markup) and its value as content, which can be text, a badge, a link or anything else. An item with no value shows `empty-text` (a dash by default) so a missing field reads as missing, not as a layout glitch, and an `actions` slot puts a copy or edit button after the value. The list itself takes a `heading` and `actions` slot for a title row.

The layout is CSS only. The items flow into as many columns as fit, never more than `--c2-description-list__grid--columns` (3) and never narrower than `--c2-description-list__grid--min-column-width` (200px), so the same markup is three columns on a wide page and one on a phone without a media query. `--c2-description-item--grid-column: 1 / -1` lets an item such as an address span the row. Labels sit above their values by default; set `--c2-description-item__label--width` to a length to put them beside the value instead, and the value still drops under its label when the item gets narrower than the label plus `--c2-description-item__value--min-width`. The two settings are independent, so labels beside values work in any number of columns: two columns of side-by-side pairs is `--c2-description-list__grid--columns: 2` plus a label width. Item variables set on the list reach every item.

The list is exposed as a `list` and each item as a `listitem` holding a `term` and its `definition`. Give the list an `aria-label` when a page has several.
