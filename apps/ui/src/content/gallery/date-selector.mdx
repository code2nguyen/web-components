## Single and multiple dates

`mode="single"` picks one date into `value`; `mode="multiple"` toggles any number of dates. `marked` puts a dot under
the days that carry something, and `renderDay` draws content of your own under the number.

<GalleryGrid min={9999}>

```html tag=MdxCodeBlock,label=Single date
<c2-date-selector mode="single" months="1" value="2026-09-17" locale="en-US" aria-label="Choose a delivery date"></c2-date-selector>
```

```html tag=MdxCodeBlock,label=Multiple dates
<style>
```

The fares card sets `renderDay` from script; a renderer can return a string, a node or a Lit template:

```ts tag=CodeBlock
import type { DateSelector } from '@c2n/components/date-selector'

const fares: Record<string, number> = { '2026-09-15': 129, '2026-09-16': 98 /* … */ }
const calendar = document.querySelector<DateSelector>('.fare-calendar')!
calendar.renderDay = ({ date, disabled }) => (disabled || !(date in fares) ? undefined : `$${fares[date]}`)
```
