`c2-secret-field` shows a secret the app already has, such as an API key, a webhook signing secret or a recovery code, the way the Stripe and OpenAI key pages do. It is masked by default, the eye button shows it, the copy button copies all of it whether it is shown or not, and `regenerable` adds a button that asks for a new one. It is a read-only display; use `c2-password-field` for a secret the user types.

The mask keeps `reveal-start` leading and `reveal-end` (default 4) trailing characters and draws the rest as twelve bullets whatever its length, so it does not give the length away. A screen reader hears "Hidden, ends with 4242" instead of the bullets, the show button is a toggle with a pressed state, and a copy is announced. The built-in labels are English and translatable.

The regenerate button only fires `regenerate`. Your app confirms it (a `c2-confirm-dialog` fits: the old secret stops working), fetches the new secret and sets `value`, usually with `revealed` and a `help` line saying it is shown once.

## Import

```typescript tag=CodeBlock
import '@c2n/components/secret-field'
```

## Usage

```html tag=UsageBlock,package=@c2n/secret-field
<style>
  .sf-row {
    width: 100%;
    max-width: 420px;
  }
</style>
<div data-label="API key">
  <c2-secret-field class="sf-row" label="Secret key" value="acme_live_51HxQ8vLkT2bR9wJmN4pZc7aYe0gDf3s4242" reveal-start="10"></c2-secret-field>
</div>
<div data-label="Regenerable, with help">
  <c2-secret-field class="sf-row" label="Signing secret" value="acme_hook_9f8e7d6c5b4a3f2e1d0c9b8a" reveal-start="10" regenerable>
    <span slot="help">Used to verify that webhook events come from us.</span>
  </c2-secret-field>
</div>
<div data-label="Shown once">
  <c2-secret-field class="sf-row" label="New API key" value="acme_test_4eC39HqLyjWDarjtT1zdp7dc" revealed hide-reveal>
    <span slot="help">Copy it now: you won't be able to see this key again.</span>
  </c2-secret-field>
</div>
```

Press the eye to show a secret and again to hide it; the copy button works either way.

## Regenerating

```html tag=CodeBlock
<c2-secret-field id="key" label="Secret key" value="acme_live_…" reveal-start="10" regenerable></c2-secret-field>
<c2-confirm-dialog id="confirm" heading="Regenerate this key?" message="The current key stops working at once." confirm-label="Regenerate" destructive></c2-confirm-dialog>

<script type="module">
  const field = document.querySelector('#key')
  const dialog = document.querySelector('#confirm')
  field.addEventListener('regenerate', async () => {
    if (!(await dialog.show())) return
    field.value = await rollKey() // your API call
    field.revealed = true
  })
</script>
```
