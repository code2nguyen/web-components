`c2-button-group` attaches related `c2-button` or `c2-icon-button` elements into one control. The default `joined` appearance shares borders and outside corners. Use `appearance="segmented"` for an inset track with an animated single-selection surface; it selects the first enabled item when `value` is omitted and supports arrow, Home and End keys. Both appearances support `orientation="vertical"`; vertical selectable groups use Up/Down while horizontal groups use Left/Right. Set `selection="single"` or `selection="multiple"` explicitly for selectable joined groups.

## Import

```typescript tag=CodeBlock
import '@c2n/components/button-group'
```

The examples use icons from the separate `@c2n/feather-icons` package: `npm install @c2n/feather-icons`.

Importing `@c2n/components/button-group` also registers `c2-button` and `c2-icon-button`.

Items identify themselves with a `value` attribute (their index otherwise). In `single` mode the group's `value` is the pressed item's value and clicking the pressed item keeps it pressed; in `multiple` mode `value` is a comma-separated list and each click toggles one entry. Set `value` from code to change the selection silently; `input` and then `change` fire for pointer and keyboard selection, with the new value in `change`'s `detail.value`. The group marks its items `toggle` in selection modes so unpressed buttons still announce `aria-pressed="false"`, and `disabled` on the group disables every item without touching the ones you disabled yourself.

The group owns the frame of its items through the button variables: `--c2-button-group--border` applies one border to every item (an outlined group), `--c2-button-group--border-radius` rounds the outside corners, and attached items overlap by `--c2-button-group__divider--width` so shared borders are drawn once. In segmented appearance, `size="s|m|l"` controls the item dimensions and `stretched` makes all items share the available width. The track, item and animated indicator each have dedicated `--c2-button-group__segmented-*` and `--c2-button-group__indicator-*` theme variables.

### Keyboard and toolbars

A single-selection group (including every segmented one) is one Tab stop, like a radio group: Tab lands on the pressed item, and the arrow keys move the selection, Home and End jump to the ends, and disabled items are skipped. A plain or `multiple` group keeps one Tab stop per item.

Add `toolbar` for a row of controls that belongs together: a formatting bar, a table's actions. The group takes the `toolbar` role and stays one Tab stop, remembering the item focused last, and the arrow keys, Home and End move focus across every focusable child — `c2-button`, `c2-icon-button`, `c2-select`, `c2-text-field`, links — without changing the selection, which Space and Enter still do. A key the focused control uses itself is left to it: Up and Down open a `c2-select`, and inside a text field the arrows and Home/End move the caret, so put a text field last in its toolbar. `toolbar` combines with any `selection` and either `orientation`.

### In a form

With a `name`, the group is a form control: it submits its pressed values under that name (one entry per value with `selection="multiple"`, nothing when none is pressed), goes back to its initial `value` when the form resets, and is disabled by a disabled `<fieldset>`. It fires `input` just before `change`, so `v-model` and Angular's `ngModel` bind to it like any other control.

```html tag=CodeBlock
<form>
  <c2-button-group name="view" appearance="segmented" value="list" aria-label="View">
    <c2-button value="list">List</c2-button>
    <c2-button value="board">Board</c2-button>
  </c2-button-group>
</form>
```
