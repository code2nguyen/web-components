## Rule builder

With `groups`, the same fields and editors are laid out as a tree of AND/OR groups, loaded the first time a builder sets it. A group can be negated, nested and removed; drag a row by its handle, or press the arrow keys on the handle, to move it into, within and out of a group. The tree reads as a sentence below it, and the `then` slot holds the actions of an automation rule. Restyle the groups with `--c2-filter-builder__group--*`, the connector column with `__joiner--*` and the sentence with `__sentence--*`.

`describe()` returns the sentence for any tree, and `filter-change` reports the tree with its groups, a negated group carrying `not: true`:

```ts tag=CodeBlock
const rule = document.querySelector('c2-filter-builder')!
rule.addEventListener('filter-change', async (event) => {
  await save({ when: event.detail.value, summary: await rule.describe() })
})
```
