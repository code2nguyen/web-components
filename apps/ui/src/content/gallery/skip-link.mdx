## Presets

Looks for `c2-skip-link`, shown as they appear when focused (each card reveals the link through `::part(link)`; in an app the link stays hidden until Tab reaches it). `--c2-skip-link--background-color`, `--c2-skip-link--color` and `--c2-skip-link--border` do most of the work; `--c2-skip-link--top` and `--c2-skip-link--inset-inline-start` move it.

<GalleryGrid>

```html tag=MdxCodeBlock,label=Default
<style>
  .shown::part(link) {
    position: static;
    clip-path: none;
    opacity: 1;
    translate: none;
  }
</style>
<c2-skip-link class="shown"></c2-skip-link>
```

  }
