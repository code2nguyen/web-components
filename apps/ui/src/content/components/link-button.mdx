`c2-link-button` is the control for "go somewhere" actions. Give it an `href` and it renders a real `<a>`, so middle-click, open in new tab and screen readers all behave natively; leave `href` out and it renders a `<button>` that fires a normal `click`. Icons go in the `prefix-icon` and `suffix-icon` slots. `external` opens the destination in a new tab (add a `c2-feather-external-link` in `suffix-icon` if you want the hint), `selected` marks the current item in a navigation, and `disabled` dims it and blocks clicks.

## Installation

```bash tag=CodeBlock
npm install @c2n/link-button
```
