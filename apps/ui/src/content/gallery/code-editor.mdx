## Presets

Curated looks for `c2-code-editor`. Open any card in the studio to start from it. The frame comes from
`--c2-code-editor--background`, `--border` and `--border-radius`; the syntax palette from the twelve
`--c2-code-editor__theme--token-*` variables, which are the same names `c2-code-viewer` uses.

<GalleryGrid min={9999}>

```html tag=MdxCodeBlock,label=Default
<c2-code-editor
  language="javascript"
  line-numbers
  value="// The default palette, on the default surface.
export function debounce(fn, wait = 200) {
  let timer
  return (...args) => {
    clearTimeout(timer)
    timer = setTimeout(() => fn(...args), wait)
  }
}"
></c2-code-editor>
```
