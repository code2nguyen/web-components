## Presets

Curated looks for `c2-action-bar`. Open any card in the studio to start from it. The `__container--*` variables
restyle the floating surface, `__label--*` the count, and `__clear--*` the clear button; `__divider--border-left: none`
drops the rule between the count and the actions. Each card sits in a frame standing in for the collection the bar
floats over.

## Floating toolbar

With `open`, the bar shows with nothing selected: a toolbar of the actions alone, with no count and no clear button,
evenly padded by `--c2-action-bar__container__toolbar--padding`. It switches to the selection layout while `count` is
above zero. `hide-on-scroll` tucks it away while its scroll container scrolls; it comes back when the scroll ends.

<ActionBarExamplesRuntime />

The French card's text comes from the app, which adds the language once; the selection card sets `count` from its
checkboxes and empties them on `clear`:

```ts tag=CodeBlock
import { addTranslations } from '@c2n/core/localize.js'

addTranslations({
  fr: {
    'action-bar': {
      selected: { one: '{0} sélectionné', other: '{0} sélectionnés' },
      clear: 'Effacer la sélection',
      actions: 'Actions sur la sélection',
      toolbar: 'Actions',
    },
  },
})

const bar = document.querySelector('c2-action-bar')
const boxes = [...document.querySelectorAll('c2-checkbox')]
const sync = () => (bar.count = boxes.filter((box) => box.checked).length)
boxes.forEach((box) => box.addEventListener('change', sync))
bar.addEventListener('clear', () => {
  boxes.forEach((box) => (box.checked = false))
  sync()
})
```
