## Presets

Timelines for order histories, changelogs and activity feeds. The marker (`__marker--size`, `--border`,
`--background`) and the connector (`__connector--width`, `--background`) set most of the character; the spacing
comes from `--c2-timeline-item--padding-bottom`. An entry's content is ordinary light DOM, so a release note can carry
headings, lists and code, styled by the page's own CSS.
