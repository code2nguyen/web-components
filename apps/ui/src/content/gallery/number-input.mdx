## Language

The step controls are named after the field ("Increase Quantity", from `aria-label`, the enclosing field's label or a
`<label for>`), and "Increase value" / "Decrease value" when it has no name. An app translates them under
`number-input` (`increaseNamed`, `decreaseNamed` take the name as `{0}`), and they follow the nearest `lang`.

<GalleryGrid>

```html tag=MdxCodeBlock,label=French
<style>
  .french {
    width: 190px;
  }
</style>
<div lang="fr">
  <c2-number-input class="french" aria-label="Quantité" value="3" min="0"></c2-number-input>
</div>
```

</GalleryGrid>

```ts tag=CodeBlock
import { addTranslations } from '@c2n/core/localize.js'

addTranslations({ fr: { 'number-input': { decrease: 'Diminuer la valeur', increase: 'Augmenter la valeur' } } })
```
