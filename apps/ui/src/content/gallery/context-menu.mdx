## Surfaces

Right-click inside a card to open its menu. The variables are set on `c2-context-menu` and inherited by the menu it opens, so one class themes the area's menu without touching the `c2-menu` markup.

<GalleryGrid>

```html tag=MdxCodeBlock,label=Default
<style>
  .area {
    display: grid;
    place-items: center;
    width: 240px;
    height: 120px;
    border: 1px dashed color-mix(in srgb, var(--c2-theme--color-on-surface, #18181b) 30%, var(--c2-theme--color-surface, #ffffff));
    border-radius: 8px;
    color: var(--c2-theme--color-on-surface-variant, #71717a);
    font-size: 14px;
  }
</style>
<c2-context-menu client:only="lit">
  <div class="area">Right-click here</div>
  <c2-menu slot="menu" aria-label="Canvas">
    <c2-menu-item value="zoom-in">Zoom in</c2-menu-item>
    <c2-menu-item value="zoom-out">Zoom out</c2-menu-item>
    <hr />
    <c2-menu-item value="reset">Reset view</c2-menu-item>
  </c2-menu>
</c2-context-menu>
```
