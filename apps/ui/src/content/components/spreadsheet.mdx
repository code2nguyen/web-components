`c2-spreadsheet` is a calculating grid for the cases where an app needs a few rows of numbers that add up: a budget,
a quote with line items, a price list, a grade sheet. It is one sheet with about twenty functions, keyboard editing
that works like Google Sheets and Excel, and copy and paste with both. It does not try to be a spreadsheet
application: there is no cell styling, no second sheet and no file import.

`data` holds the raw inputs row by row. A string starting with `=` is a formula, a leading `'` keeps the rest as
text, and a number typed as `10%` or `$12` keeps that look. `columns` is either a count or one object per column with
a `label`, a `width` in pixels, a `format` (`general`, `number`, `currency`, `percent`, `text`) and an `align`. The
column letter stays in the header next to the label, because formulas use the letter. Edits write a new array to
`data` and fire `cell-change` with every cell the user changed.

Formulas support `+ - * / ^ &`, comparisons, a `%` suffix, `A1` references and `A1:B5` ranges, and the functions
`SUM`, `AVERAGE`, `MIN`, `MAX`, `COUNT`, `COUNTA`, `ROUND`, `ABS`, `IF`, `IFERROR`, `AND`, `OR`, `NOT`, `SUMIF`,
`CONCAT`, `LEN`, `UPPER`, `LOWER`, `TRIM` and `TODAY`. Add your own through the `functions` property. Changing a cell
recalculates only the cells that read it. Errors stay in their cell (`#DIV/0!`, `#REF!`, `#NAME?`, `#VALUE!`,
`#CIRC!`) and the tooltip says why.

Arrows move, Shift+arrows extend the range, typing replaces the cell, Enter, F2 or a double-click edit it, Enter and
Tab commit, Escape cancels and Delete clears. Ctrl/⌘+C, X and V copy, cut and paste tab-separated text, so a range
copied from Excel or Sheets pastes straight in; a formula copied inside the grid moves its references when pasted
(`=B2*C2` one row down becomes `=B3*C3`, and `$` pins a row or column). Ctrl/⌘+Z and Y undo and redo. Tab outside an
edit leaves the grid.

A paste larger than the space left grows the sheet to fit rather than dropping what does not fit. To change the
sheet's shape from code, call `insertRows(index, count)`, `insertColumns(index, count)`, `deleteRows(index, count)` or
`deleteColumns(index, count)` with a zero-based index (`0` for the top or first column, `rows` or the column count
for the end). The cells after it move, column options move with their columns, and formulas keep reading the same
cells: `=SUM(B1:B5)` becomes `=SUM(B1:B6)` when a row goes in inside the range and `=SUM(B1:B4)` when one comes out,
and a reference to a deleted cell becomes `#REF!`. These calls clear the undo history; at least one row and one
column always stay.

Drag the right edge of a column header to resize the column, or double-click it to fit the column to its widest
cell. The new width is written to `columns` and reported by `column-resize`, so an app can save it and hand it back.
A column stops at its `minWidth` (32px by default); `resizable: false` on a column, or `resizable="false"` on the
sheet, turns resizing off.

## Usage

```html tag=UsageBlock,package=@c2n/spreadsheet
<style>
  .sheet-demo {
    width: 100%;
  }
</style>
<div data-label="Formula bar and summary">
  <c2-spreadsheet
    class="sheet-demo"
    label="Team offsite budget"
    rows="10"
    formula-bar
    summary
    columns='[{"label":"Item","width":150},{"label":"Category","width":100},{"label":"Qty","width":60,"format":"number"},{"label":"Unit cost","width":100,"format":"currency"},{"label":"Total","width":110,"format":"currency"}]'
    data='[["Flights","Travel",6,289,"=C1*D1"],["Hotel, 2 nights","Lodging",3,412,"=C2*D2"],["Team dinner","Food",1,640,"=C3*D3"],["Lunches","Food",12,18.5,"=C4*D4"],[],["Subtotal","","","","=SUM(E1:E4)"],["Contingency","","","10%","=E6*D7"],["Total","","","","=E6+E7"]]'
  ></c2-spreadsheet>
</div>
<div data-label="Right-click menu">
  <c2-context-menu client:only="lit" data-spreadsheet-demo="context-menu" menu-label="Sheet actions">
    <c2-spreadsheet
      class="sheet-demo"
      label="Price list"
      rows="5"
      columns='[{"label":"Product","width":140},{"label":"Price","format":"currency"},{"label":"Qty","format":"number"},{"label":"Total","format":"currency"}]'
      data='[["Notebook",4.5,10,"=B1*C1"],["Pen",1.2,25,"=B2*C2"],["Stapler",8.9,2,"=B3*C3"],["Total","","","=SUM(D1:D3)"]]'
    ></c2-spreadsheet>
  </c2-context-menu>
</div>
<div data-label="Read-only">
  <c2-spreadsheet
    class="sheet-demo"
    label="Quiz scores"
    rows="5"
    readonly
    summary
    columns='[{"label":"Student"},{"label":"Quiz 1","format":"number"},{"label":"Quiz 2","format":"number"},{"label":"Average","format":"number"}]'
    data='[["Linh",18,17,"=AVERAGE(B1:C1)"],["Mateo",14,19,"=AVERAGE(B2:C2)"],["Aiko",20,16,"=AVERAGE(B3:C3)"],["Noor",12,15,"=AVERAGE(B4:C4)"],["Class","=AVERAGE(B1:B4)","=AVERAGE(C1:C4)","=AVERAGE(D1:D4)"]]'
  ></c2-spreadsheet>
</div>
<div data-label="Blank sheet">
  <c2-spreadsheet class="sheet-demo" label="Scratch sheet" rows="6" columns="6"></c2-spreadsheet>
</div>
```

### Insert and delete from a context menu

Wrapped in a `c2-context-menu`, a right-clicked cell, row header or column header selects itself (unless it is
already selected) and answers the menu with a `SpreadsheetContextMenuData`: the `area` (`cell`, `row`, `column` or
`corner`), the selected `range` and `active` cell, and the zero-based `start` and `end` of the selection. The sheet
has no built-in menu, so the app decides what to offer:

```typescript tag=CodeBlock
import { html } from 'lit'
import type { ContextMenu } from '@c2n/components/context-menu'
import type { Spreadsheet, SpreadsheetContextMenuData } from '@c2n/components/spreadsheet'

const menu = document.querySelector<ContextMenu>('c2-context-menu')!

menu.renderContextMenu = ({ data, source }) => {
  if (source?.localName !== 'c2-spreadsheet') return null
  const { area } = data as SpreadsheetContextMenuData
  return html`
    ${area !== 'column' ? html`<c2-menu-item value="row-above">Insert row above</c2-menu-item>` : ''}
    ${area !== 'row' ? html`<c2-menu-item value="column-left">Insert column left</c2-menu-item>` : ''}
    <hr />
    ${area !== 'column' ? html`<c2-menu-item value="delete-rows" destructive>Delete rows</c2-menu-item>` : ''}
    ${area !== 'row' ? html`<c2-menu-item value="delete-columns" destructive>Delete columns</c2-menu-item>` : ''}
  `
}

menu.addEventListener('context-menu-select', ({ detail }) => {
  const sheet = detail.context.source as Spreadsheet
  const { start, end } = detail.context.data as SpreadsheetContextMenuData
  if (detail.value === 'row-above') sheet.insertRows(start.row, end.row - start.row + 1)
  if (detail.value === 'column-left') sheet.insertColumns(start.column, end.column - start.column + 1)
  if (detail.value === 'delete-rows') sheet.deleteRows(start.row, end.row - start.row + 1)
  if (detail.value === 'delete-columns') sheet.deleteColumns(start.column, end.column - start.column + 1)
})
```

Read the result from script with `getValue('E8')`, write a cell with `setInput('C1', 8)`, select a range with
`select('B1:E5')` and export the computed values with `toCSV()` or `toTSV()`. `selection-change` does not bubble, so
listen on the element itself.

```typescript tag=CodeBlock
const sheet = document.querySelector('c2-spreadsheet')!
sheet.functions = { TAX: ([amount]) => (typeof amount === 'number' ? amount * 0.2 : 0) }
sheet.addEventListener('cell-change', (event) => save(sheet.data, event.detail.changes))
```
