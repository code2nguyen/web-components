## Painted schedules

With `paint`, the user drags across days and times to mark weekly ranges such as opening hours or when someone can
work; a stroke that starts on a painted cell clears instead. The planner reports each stroke through `ranges-change`
and the app assigns `detail.ranges` to `ranges`, as these cards do. From the keyboard, Tab to the cursor cell, move it
with the arrows and press Space.

`renderRange` draws the content of each painted range from `{ range, dayName }`; the planner keeps the block, its place
and its parts (`range`, and `range-<value>` for a value that is a plain word, which the cards above colour):

```ts tag=CodeBlock
import { html } from 'lit'
import type { WeekPlannerRangeContext } from '@c2n/components/week-planner'

planner.paint = true
planner.paintValue = '21'
planner.renderRange = ({ range }: WeekPlannerRangeContext) => html`<strong part="temperature">${range.value}°C</strong> <span>${range.start}–${range.end}</span>`
planner.addEventListener('ranges-change', ({ detail }) => (planner.ranges = detail.ranges))
// An action of your own in the `actions` slot:
copyButton.addEventListener('click', () => planner.copyDay('mon', ['tue', 'wed', 'thu', 'fri']))
```
