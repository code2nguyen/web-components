`c2-avatar` shows a person or entity. It resolves its content in order: the `src` image (a broken image fires `error` and falls back to the initials), then slotted content such as an icon or emoji, then the initials computed from `name`. `initial-count="2"` picks the first and last word of a longer name, and `initials` overrides the computation. `auto-color` derives a stable background hue from the name, `status` adds a presence dot, and the `badge` slot replaces the dot with your own element. One `--c2-avatar--size` token drives the width, height and font size. The same package also exports `c2-avatar-group`, which stacks avatars responsively and replaces those that no longer fit with an automatic count.

## Installation

```bash tag=CodeBlock
npm install @c2n/avatar
```

Add `editable` when the person should be able to choose, replace, or remove their own avatar. Clicking the avatar opens an image picker and immediately previews the local file. Existing images receive a separate remove action; removing one restores initials or slotted fallback content. Use `accept` and `max-size` to constrain the file before your application uploads it.

```js tag=CodeBlock
const avatar = document.querySelector('c2-avatar')

avatar.addEventListener('avatar-change', async event => {
  const remoteUrl = await uploadAvatar(event.detail.file)
  avatar.src = remoteUrl
})

avatar.addEventListener('avatar-remove', () => {
  deleteAvatar()
})
```

The component owns selection and the local preview, not network transport. `avatar-change` provides the selected `File`; `avatar-remove` identifies the previous source. Invalid files emit `file-reject`. Call `browse()` or `removeImage()` when external controls need to trigger the same actions, and customize their graphics with the `edit-icon` and `remove-icon` slots.
