import { ColorSelect } from '@c2n/color-select'

`c2-color-select` is a component composed by `c2-color-area` and `c2-color-slider` allows users to select all properties of a color visually.

## Installation

```bash tag=CodeBlock
npm install @c2n/color-select
```

## Usage

```html tag=UsageBlock,package=@c2n/color-select
<style>
  .large-swatch {
    --c2-color-select--width: 32px;
    --c2-color-select--height: 32px;
    --c2-color-select--border-top-left-radius: 8px;
    --c2-color-select--border-top-right-radius: 8px;
    --c2-color-select--border-bottom-left-radius: 8px;
    --c2-color-select--border-bottom-right-radius: 8px;
  }
</style>
<div data-label="Default">
  <c2-color-select color="#ff726b"></c2-color-select>
</div>
<div data-label="Large swatch">
  <c2-color-select class="large-swatch" color="#2563eb"></c2-color-select>
</div>
```
