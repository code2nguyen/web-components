The Custom cards card draws each card's content with `renderSource`, the Streaming card adds a cited sentence as a model would and the list follows it, and the French card's text is the translation an app adds:

```ts tag=CodeBlock
import { addTranslations } from '@c2n/core/localize.js'

addTranslations({ fr: { 'citation-list': { summary: { one: '{0} source consultée', other: '{0} sources consultées' }, card: 'Source {0} : {1}' } } })

list.renderSource = ({ source, number }) => `[${number}] ${source.title ?? source.href}`
```
