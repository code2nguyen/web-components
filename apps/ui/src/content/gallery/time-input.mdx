## Presets

Each treatment changes only the public CSS variables: the field's `background`, `border` and `border-radius` do most of the work.

<GalleryGrid>

```html tag=MdxCodeBlock,label=Default
<style>
  .default {
    width: 160px;
  }
</style>
<c2-time-input class="default" aria-label="Meeting time" value="09:30"></c2-time-input>
```

```html tag=MdxCodeBlock,label=Soft
<style>
  .soft {
    width: 160px;
    --c2-time-input--background: var(--c2-theme--color-surface-container, #f4f4f5);
    --c2-time-input--border: 1px solid transparent;
    --c2-time-input__hover--border: 1px solid var(--c2-theme--color-outline, #d4d4d8);
    --c2-time-input--border-radius: 10px;
  }
</style>
<c2-time-input class="soft" aria-label="Meeting time" value="09:30"></c2-time-input>
```

```html tag=MdxCodeBlock,label=Dark
<style>
  .dark {
    width: 160px;
    --c2-time-input--background: var(--c2-theme--color-inverse-surface, #18181b);
    --c2-time-input--color: color-mix(in srgb, var(--c2-theme--color-on-surface, #18181b) 5%, var(--c2-theme--color-surface, #ffffff));
    --c2-time-input--border: 1px solid color-mix(in srgb, var(--c2-theme--color-on-surface, #18181b) 82%, var(--c2-theme--color-surface, #ffffff));
    --c2-time-input__hover--border: 1px solid color-mix(in srgb, var(--c2-theme--color-on-surface, #18181b) 60%, var(--c2-theme--color-surface, #ffffff));
    --c2-time-input__focus--border: 1px solid var(--c2-theme--color-outline-strong, #a1a1aa);
    --c2-time-input__focus--outline: 2px solid rgba(244, 244, 245, 0.25);
    --c2-time-input__clock-icon--color: var(--c2-theme--color-outline-strong, #a1a1aa);
  }
</style>
<c2-time-input class="dark" aria-label="Meeting time" value="09:30"></c2-time-input>
```

</GalleryGrid>
