## Maps

The frame is the map's own variables (`--c2-google-map__container--*`). Pins and route lines are drawn by Google, so
their colours are read from `--c2-google-map-marker__*` and `--c2-google-map-route__*` when they are drawn.

The notices shown in place of a map (loading, a missing key, no imagery, the pegman hint) are message tokens. An app
translates them once with `addTranslations`; each element shows the language of its nearest `lang`. The `map-error`
event keeps the English text for the developer.

```ts tag=CodeBlock
import { addTranslations } from '@c2n/core/localize.js'

addTranslations({
  fr: {
    'google-map': {
      loadingMap: 'Chargement de la carte…',
      loadingStreetView: 'Chargement de Street View…',
      missingKey: 'Définissez une clé API Google Maps pour afficher cette carte.',
      loadFailed: 'La carte n’a pas pu être chargée.',
      authFailed: 'Google Maps a refusé la clé API. Vérifiez ses restrictions de référent HTTP et d’API.',
      noImagery: 'Street View n’a pas d’images près de ce lieu.',
      pegman: 'Déposez le bonhomme sur la carte pour regarder autour.',
    },
  },
})
```
