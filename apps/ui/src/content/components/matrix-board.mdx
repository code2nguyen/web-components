`c2-matrix-board` is a [`c2-kanban`](/web-components/components/kanban) laid out in two dimensions: an item sits in the
cell its row and its column name, and people move it to any other cell with a pointer or the keyboard. Each cell shows
its card count, can carry a name and a colour band, and the axes take a title. A 9-box talent grid (performance by
potential), a 5 by 5 risk matrix (likelihood by impact) and an Eisenhower matrix (urgent by important) read this way.

## Import

```typescript tag=CodeBlock
import '@c2n/components/kanban/matrix-board'
```

The entry registers `c2-matrix-board` and `c2-kanban-column`, which draws each cell.

The axes come from `rows` (top to bottom) and `columns` (left to right): `{ "id", "label" }` objects, or plain values
that are their own label (`rows='[5, 4, 3, 2, 1]'`). An item sits in the cell its `row` and `column` fields name
(`row-field`, `column-field`); an item whose row or column matches none is not shown. Ids may be numbers: they are
compared as text, and a move writes back the id as `rows` or `columns` gave it.

`cells` names cells and colours them: `{ "row", "column", "label", "band" }`, where `band` is 1 to 5 and picks
`--c2-matrix-board__band-<n>--background-color`. The default bands run from green (1) to red (5) as translucent washes,
so they read in both themes; a 9-box usually runs the other way, which is a matter of which band a cell takes. A cell
left out of `cells` has no name and the plain cell background. Every cell shows its count; an empty cell shows no hint.

`row-title` and `column-title` label the axes: the row title reads bottom to top left of the row labels, the column
title sits under the column labels. Both are read in each cell's accessible name ("Star (Potential: High, Performance:
High)"), which is also what moves announce. Anything in the board's default slot shows under the grid, such as a
legend of the bands.

Everything else is the kanban's: `items`, `item-key`, `label-field`, `description-field`, `renderItem` and `editable`
work the same, and a card's box takes the `--c2-kanban-column__card--*` variables, set on the board. With the keyboard
the board is one tab stop; the arrow keys move focus within a cell and on to the nearest cell with cards. Space picks a
card up, the arrow keys move it (Up from a cell's first card reaches the bottom of the cell above, Down from its last
the top of the cell below, Left and Right the next column), Home and End move it within its cell, Space drops it and
Escape returns it.

A drop fires `card-move` with the kanban's detail plus the rows: `fromRow`/`toRow` and `fromColumn`/`toColumn` are
the axis ids of the two cells, as strings.

```js tag=CodeBlock
board.addEventListener('card-move', (event) => {
  const { key, toRow, toColumn } = event.detail
  saveRating(key, { potential: toRow, performance: toColumn })
})
```

The announcements and the screen-reader instructions are message tokens of the `matrix-board` catalog, translated with
`addTranslations({ fr: { 'matrix-board': { … } } })`; the API tab lists them.
