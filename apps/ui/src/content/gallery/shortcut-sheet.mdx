## Presets

`renderItem` draws the content of each row; the sheet keeps the row, its list and its search. Give the elements it returns a `part` to style them from the page:

```ts tag=CodeBlock
import { html } from 'lit'

sheet.renderItem = ({ entry }) => html`<span part="command">${entry.description}</span><code part="code">${entry.labels.join(' · ')}</code>`
```

The sheet's text is a message of the component; an app adds its languages:

```ts tag=CodeBlock
import { addTranslations } from '@c2n/core/localize.js'

addTranslations({
  fr: {
    shortcut: {
      title: 'Raccourcis clavier',
      search: 'Rechercher un raccourci',
      general: 'Général',
      show: 'Afficher les raccourcis clavier',
      or: 'ou',
      then: 'puis',
      results: { one: '{0} raccourci', other: '{0} raccourcis' },
      noResults: 'Aucun raccourci ne correspond à « {0} »',
      empty: 'Aucun raccourci clavier',
    },
  },
})
```
