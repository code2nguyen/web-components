## Presets

Looks for `c2-markdown`. Typography (`--c2-markdown--font-size`, `--line-height`, `--block-gap`), headings, links, inline code, tables and blockquotes each have their own variables. Code blocks, math and diagrams keep their own components' variables, which also work when set on this element.
