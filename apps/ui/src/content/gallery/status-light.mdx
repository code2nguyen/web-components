## Presets

Curated looks for `c2-status-light`. Open any card in the studio to start from it. `--c2-status-light--background` with the paddings turns the light into a pill, `--c2-status-light__dot--clip-path` and `--border-radius` code each tone with a shape as well as a colour, and the per-tone `--c2-status-light__dot__<tone>--background` variables recolour a tone everywhere.
