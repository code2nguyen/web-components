## Maps

The frame is the map's own variables (`--c2-google-map__container--*`). Pins and route lines are drawn by Google, so
their colours are read from `--c2-google-map-marker__*` and `--c2-google-map-route__*` when they are drawn.

<GalleryGrid>

```html tag=MdxCodeBlock,label=Default
<c2-google-map center="10.7769,106.7009" zoom="13"></c2-google-map>
```

```html tag=MdxCodeBlock,label=Rounded card
<style>
  .map-card {
    width: 100%;
    --c2-google-map__container--height: 260px;
    --c2-google-map__container--border-radius: 14px;
    --c2-google-map__container--border: 1px solid var(--c2-theme--color-outline-variant, #e4e4e7);
  }
</style>
<c2-google-map class="map-card" center="21.0285,105.8542" zoom="14" disable-default-ui>
  <c2-google-map-marker position="21.0285,105.8542" label="Hoan Kiem Lake"></c2-google-map-marker>
</c2-google-map>
```

```html tag=MdxCodeBlock,label=Coloured pins
<style>
  .map-pins {
    width: 100%;

  }

  <c2-google-map-marker class="pin-open" position="10.7725,106.6980" label="Store 1, open" glyph="1"></c2-google-map-marker>
```
