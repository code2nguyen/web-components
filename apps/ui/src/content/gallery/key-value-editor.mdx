## Presets

The key and value columns share one grid with the headers, so `--c2-key-value-editor--key-width` and `--value-width` resize both. The `__field` variables style every input and `__header--display: none` drops the column headers.

## Language

<KeyValueEditorExamplesRuntime />

The column headings, the placeholders, the add button, the empty state and the validation messages are message tokens: an app translates them once with `addTranslations`, and each editor speaks the language of its nearest `lang`. The `*-label`, `*-placeholder` and `*-message` attributes still override one instance.

<GalleryGrid min="420">

```html tag=MdxCodeBlock,label=En français,description=The headings and placeholders and messages in the language of the page,useWhen=The application is translated
<div lang="fr">
  <c2-key-value-editor
    client:only="lit"
    label="Variables d'environnement"
    entries='[{"key":"API_URL","value":"https://api.example.com"},{"key":"API_URL","value":"https://api.example.fr"},{"key":"","value":""}]'
  ></c2-key-value-editor>
</div>
```

</GalleryGrid>
