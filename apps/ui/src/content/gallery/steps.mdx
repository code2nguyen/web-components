## Presets

Curated looks for `c2-steps`. Open any card in the studio to start from it. Two variables do most of the work:
`--c2-step__rail--width` turns a trace into a stepper, and `--c2-step__row--border-bottom` turns a stepper back into
a table of rows. Every step is a row and every row is on screen: a sub-step is indented until its marker sits under
its parent's label, which is all the nesting needs. `--c2-step__guide--width: 1px` adds file-tree rules on top of
that, and the `toggle` slot adds a chevron — both off by default.

The task list from data hands each row its status tag through `renderTrailing`, and the curriculum from data writes
each section's count and minutes there from `context.progress`. The stage path's action and its
guidance, and the trace's header buttons, are a few lines of the app's own code:

```ts tag=CodeBlock
import { html } from 'lit'
import type { StepNode } from '@c2n/components/steps'

const TAGS = { success: ['success', 'Completed'], current: ['primary', 'In progress'], pending: ['neutral', 'Not started'] }
tasks.renderTrailing = ({ node, status }) => {
  const [tone, text] = node.disabled ? ['neutral', 'Cannot start yet'] : (TAGS[status] ?? TAGS.pending)
  return html`<c2-badge tone=${tone}>${text}</c2-badge>`
}

// Each lesson node of `steps` carries its length in `minutes`; a section's is the sum of its lessons'.
const minutesOf = (node: StepNode & { minutes?: number }): number =>
  (node.children?.length ? node.children.reduce((sum, child) => sum + minutesOf(child), 0) : (node.minutes ?? 0))
course.renderTrailing = ({ node, progress }) =>
  progress ? `${progress.completed}/${progress.total} · ${minutesOf(node)} min` : `${minutesOf(node)} min`

path.addEventListener('selection-change', ({ detail }) => (guidance.textContent = GUIDANCE[detail.value]))
markCurrent.addEventListener('click', () => {
  const index = Number(path.querySelector(`c2-step[value="${path.selected}"]`).path) - 1
  if (index >= 0) path.current = index
})
expandAll.addEventListener('click', () => trace.expandAll())
```
