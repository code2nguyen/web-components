## Presets

Looks and jobs for `c2-barcode-scanner`. The window's shape and colours, the scan line and the stage set the style. Every card but the first films a pretend conveyor belt through `streamSource` (the code is under the grid) and reads it with the real decoder, so the gallery never asks for your camera.

The cards hand the scanner a canvas that films a printed label, in place of the camera, and the "Own decoder" card reads the picture with the app's own function:

```ts tag=CodeBlock
import type { BarcodeDecoder, BarcodeScanner, CameraStreamSource } from '@c2n/components/barcode-scanner'

const scanner = document.querySelector<BarcodeScanner>('c2-barcode-scanner')!

// Any MediaStream works: a chosen device, a WebRTC stream, or a canvas in a demo or a test.
const source: CameraStreamSource = async () => labelCanvas.captureStream(15)
scanner.streamSource = source

// The decoder receives the picture inside the scan window and returns the codes it finds.
const decoder: BarcodeDecoder = async (frame, { formats }) => {
  const codes = await myReader.read(frame, formats)
  return codes.map((code) => ({ value: code.text, format: code.format }))
}
scanner.decoder = decoder

scanner.addEventListener('scan', (event) => count(event.detail.value))
```
