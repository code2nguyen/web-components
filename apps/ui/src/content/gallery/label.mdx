## Typography

A label inherits the text around it; each look below sets a few `--c2-label__container--*` variables on top.

<GalleryGrid>

```html tag=MdxCodeBlock,label=Default
<c2-label required>Email address</c2-label>
```

```html tag=MdxCodeBlock,label=Medium
<style>
  .medium {
    --c2-label__container--font-size: 14px;
    --c2-label__container--font-weight: 500;
    --c2-label__container--color: #18181b;
  }
</style>
<c2-label class="medium" required>Email address</c2-label>
```

## Required markers

The asterisk is the default content of the `required-indicator` slot; restyle it or replace it with text.

<GalleryGrid>

```html tag=MdxCodeBlock,label=Bold red
<style>
  .bold-red {
    --c2-label__container--font-size: 14px;
    --c2-label__container--font-weight: 500;
    --c2-label__required-indicator--color: #dc2626;
    --c2-label__required-indicator--font-weight: 700;
    --c2-label__required-indicator--font-size: 16px;
  }
</style>
<c2-label class="bold-red" required>Password</c2-label>
```

```html tag=MdxCodeBlock,label=Subtle
<style>
  .subtle {
    --c2-label__container--font-size: 14px;
    --c2-label__container--font-weight: 500;
    --c2-label__container--gap: 2px;
    --c2-label__required-indicator--color: #a1a1aa;
  }
</style>
<c2-label class="subtle" required>Password</c2-label>
```

```html tag=MdxCodeBlock,label=Text indicator
<style>
  .text-indicator {
    --c2-label__container--font-size: 14px;
    --c2-label__container--font-weight: 500;
    --c2-label__container--gap: 6px;
    --c2-label__required-indicator--color: #71717a;
    --c2-label__required-indicator--font-size: 12px;
    --c2-label__required-indicator--font-weight: 400;
  }
</style>
<c2-label class="text-indicator" required>Password <span slot="required-indicator">(required)</span></c2-label>
```

</GalleryGrid>
