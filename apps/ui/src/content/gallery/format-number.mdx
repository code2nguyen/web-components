## Presets

Curated looks for `c2-format-number`. Open any card in the studio to start from it. The number inherits the surrounding text, so colour, size and weight do most of the work; the `unit` variables set the currency symbol or suffix apart from the digits, and the negative and positive colours read profit and loss at a glance.
