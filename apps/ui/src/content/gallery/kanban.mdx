## Presets

The cards are your own markup, so most of a board's look lives in their CSS. The board's variables set the column
box (`--c2-kanban__column--*`), the drop gap and the drag lift; the column's set the header dot, count and empty hint.

<GalleryGrid>

```html tag=MdxCodeBlock,label=Default
<c2-kanban client:only="lit" editable aria-label="Tasks">
  <c2-kanban-column column-id="todo" label="To do"></c2-kanban-column>
  <c2-kanban-column column-id="done" label="Done"></c2-kanban-column>
  <div data-column="todo">Write the release notes</div>
  <div data-column="todo">Update the screenshots</div>
  <div data-column="done">Fix the build</div>
</c2-kanban>
```
