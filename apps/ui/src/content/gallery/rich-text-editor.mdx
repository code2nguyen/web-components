## Merge fields

List the fields in `merge-fields` and their `{{tokens}}` in the value become chips the caret steps over; the value keeps the tokens. `{{first_name|there}}` carries a fallback. `--c2-rich-text-editor__merge-field--*` styles the chip.

</style>

  class="merge-editor"
  label="Email body"
  merge-fields='[{"name":"first_name","label":"First name","fallback":"there"},{"name":"company","label":"Company"},{"name":"plan","label":"Plan"}]'

<RichTextEditorExamplesRuntime />

The field menu is the app's: put it in `toolbar-end` (or open it on a `trigger` such as `{{`), and insert the chosen field with `insertMergeField()`. Clicking a chip, or Enter on a selected one, fires `merge-field-activate`; `insertMergeField()` then replaces that chip, which is how an app edits its fallback. `renderMergeField` draws a chip's content, and a `part` in it can be styled from the page.

```ts tag=CodeBlock
import { html, nothing } from 'lit'

menu.addEventListener('menu-select', ({ detail }) => setTimeout(() => editor.insertMergeField(detail.value)))

editor.addEventListener('merge-field-activate', async ({ detail }) => {
  const fallback = await askForFallback(detail.field.label, detail.fallback, detail.rect)
  editor.insertMergeField(detail.field.name, { fallback })
})

editor.renderMergeField = ({ label, fallback }) =>
  html`${label}${fallback ? html`<span part="merge-field-fallback"> · ${fallback}</span>` : nothing}`
```
