`c2-swipe-action` wraps one row of a list. Drag the row toward the end edge to reveal the `start` actions, toward the
start edge to reveal the `end` actions; release past halfway (or flick) and the row stays open, short of it and it
slides back. A tap on the open row, a press outside it, Escape or activating an action closes it. Vertical drags are
left to the page, so a list of rows still scrolls. The actions stay in the Tab order while hidden, and focusing one
opens its side, so every action is reachable from the keyboard. With `full-swipe`, dragging past 60% of the row's
width arms the outermost action, and releasing there clicks it: the "swipe all the way to delete" gesture.

## Import

```typescript tag=CodeBlock
import '@c2n/components/swipe-action'
```

**In a list.** Wrap each `c2-list-item` of a `c2-list` in a `c2-swipe-action`: the list finds the row inside the
wrapper, so arrow keys, typeahead and selection work as before. Give each action a shortcut with
`aria-keyshortcuts`: the key runs that action while its row has focus, and a row with shortcuts takes its hidden
actions out of the Tab order, so the list stays one Tab stop. Name the shortcuts where a screen reader reads them,
such as the row's description.

The icons below come from `npm install @c2n/feather-icons`. `open` reflects the side that is shown; listen to
`open-change` to follow it, and to `full-swipe` (cancelable) to confirm a destructive full swipe:

```typescript tag=CodeBlock
row.addEventListener('full-swipe', (event) => {
  if (!confirm('Delete this message?')) event.preventDefault()
})
```
