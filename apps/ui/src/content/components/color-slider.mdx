`c2-color-slider` allows users to select hue of a color from 0 to 360.

To style the left edge of the gradient, set `--c2-color-slider--border-left`. The old `--c2-color-slider--borde-leftr` spelling has been removed. For rounded corners, use the four `--c2-color-slider--border-*-radius` properties; the old radius shorthand had no effect and is no longer published.

## Installation

```bash tag=CodeBlock
npm install @c2n/color-slider
```

## Usage

```html tag=UsageBlock,package=@c2n/color-slider
<style>
  .compact-hue-slider {
    --c2-color-slider--width: 180px;
    --c2-color-slider--height: 12px;
    --c2-color-slider__color-handle--width: 16px;
    --c2-color-slider__color-handle--height: 16px;
  }
</style>
<div data-label="Default">
  <c2-color-slider></c2-color-slider>
</div>
<div data-label="Compact">
  <c2-color-slider class="compact-hue-slider"></c2-color-slider>
</div>
```
