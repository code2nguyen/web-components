## Inline prompt

A control with `data-prompt` turns the toolbar into a prompt at the same anchor: the `prompt` slot holds the field and the quick actions, the `result` slot the answer and what to do with it. The selection stays frozen while the reader types. Escape closes it.

The streaming card's application code: the toolbar keeps the selection while the reader types, so the answer replaces exactly what was selected.

```ts tag=CodeBlock
toolbar.addEventListener('selection-action', async ({ detail }) => {
  const range = toolbar.selection?.range
  if (detail.action === 'replace' && range) {
    range.deleteContents()
    range.insertNode(document.createTextNode(answer.value))
  }
  const done = ['replace', 'discard'].includes(detail.action)
  if (done) toolbar.prompting = false
  if (detail.action === 'shorten') {
    streamInto(answer, await ask('Make it shorter', detail.text))
  }
})
// Escape, or disabling the toolbar, closes the prompt: stop the call.
toolbar.addEventListener('toggle', ({ detail }) => {
  if (!detail.open) controller.abort()
})
```
