## Presets

Curated looks for `c2-tree`. Open any card in the studio to start from it. The container is `--c2-tree--*` (background, padding, borders, radius, `max-height`); every row is `--c2-tree-item--*`, where `row--indent` and `row--border-radius` do most of the work — set `row--border-radius` to `0` for the edge-to-edge bands of a layers panel, and `actions--opacity` to `1` to stop the trailing actions hiding until hover. Add `children-outline` for the indent rules, then colour them with `guide--color`.

## Drops from outside the tree

A tree with `drop-kind` and `reorderable` takes nodes dropped from outside it. The source writes them with
`writeItemPayload` from `@c2n/core/controllers/drop-zone.js` under the same kind. The middle of a row nests them under
it, its top or bottom quarter puts them before or after it; a value the tree already holds is refused. A tree built from
`items` adds the nodes itself and fires `item-drop`; one written in markup hands the app `parentElement` and `before`.
Drag a file onto a folder.

```ts tag=CodeBlock
import { writeItemPayload } from '@c2n/core/controllers/drop-zone.js'

// The source: anything draggable that writes nodes under the tree's drop-kind.
chip.draggable = true
chip.addEventListener('dragstart', (event) => writeItemPayload(event.dataTransfer!, 'tree-node', [{ value: 'guide', label: 'guide.md' }]))

// A tree built from `items` adds the nodes itself; the page only clears its tray.
tree.addEventListener('item-drop', ({ detail }) => {
  for (const node of detail.items) tray.querySelector(`[data-value="${node.value}"]`)?.remove()
})
```

A tree with `drag-kind` lets its rows leave, each with its subtree: a pointer drag carried off the tree drops the row
on the tree under the pointer, each row's handle starts a drag the browser carries (dropped back on its own tree it moves the row there; a drop outside c2n, in another window too, takes a copy), and
`moveItemTo(target, value)` is the keyboard path an application wires to a command. The tree the row left fires
`item-move-out` and, when built from `items`, takes it out itself. Drag a row to the other tree, or use its arrow button.

```ts tag=CodeBlock
// <c2-tree reorderable drag-kind="tree-node" drop-kind="tree-node" items="…"> on both trees: rows move by pointer or
// handle, and each tree updates its own `items`.

// The keyboard path: a command in each row's actions.
drafts.renderActions = ({ node }) => html`<c2-button aria-label="Publish ${node.label}" @click=${() => drafts.moveItemTo(published, node.value)}>→</c2-button>`

// Save both sides of a move.
published.addEventListener('item-drop', () => queueMicrotask(() => save(published.items)))
drafts.addEventListener('item-move-out', () => queueMicrotask(() => save(drafts.items)))
```

## Language

The empty state and the announcements of a moved row are message tokens: an app translates them once with `addTranslations`, and each tree speaks the language of its nearest `lang`.

```ts tag=CodeBlock
import { addTranslations } from '@c2n/core/localize.js'

addTranslations({
  fr: {
    tree: {
      moved: '{0} déplacé en position {1} sur {2}.',
      movedInto: '{0} déplacé dans {1}, position {2} sur {3}.',
      cannotMove: '{0} ne peut pas aller là.',
      cancelled: 'Déplacement de {0} annulé.',
      movedOut: '{0} a quitté l’arbre.',
      empty: 'Aucun élément',
    },
  },
})
```
