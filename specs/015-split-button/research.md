Takeaways:

- The industry is split between a dedicated component and a recipe. The recipe fails on the details that make it worth a component here: shared radii and seam, the menu anchored to the _whole_ control, the caret's accessible name, the open-state chevron, and "remember the choice". c2 already has the recipe pieces (`c2-button-group` + `c2-menu`), and the docs show neither combined, so a component is justified.
- Two seam models (joined divider vs M3 gap) are both common; one variable can serve both.
- Variants are colour presets everywhere; in c2 that is CSS, not an attribute (same as `c2-button`).

## 2. Accessibility

- No ARIA role exists for a split button ([PFWG 2014](https://lists.w3.org/Archives/Public/public-pfwg/2014Aug/0045.html)). It is two controls: a plain button and an [APG menu button](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/) (`aria-haspopup="menu"`, `aria-expanded`, optional `aria-controls`).
- Menu button keys: Enter / Space / ↓ open on the first item, ↑ on the last; Escape closes and returns focus to the trigger. `c2-menu` already implements all of it.
- **Two tab stops** is the norm (eBay, Visma, Fluent, Material). A one-stop variant (↓ on the main opens the menu) exists only as folklore; not adopted.
- Caret name: "More options" (M3, Web Awesome), "Additional actions" (Carbon), labelled by the primary (Fluent). Chosen: localised "More {label} options", which carries the primary's meaning without the double announcement Fluent's labelledby produces.
- "Remember last choice" is described only by [web.dev](https://web.dev/articles/building/a-split-button-component) and was rejected by Polaris. It must be opt-in; in it, items are `menuitemradio` with `aria-checked`, and the primary's name changes.
- Guidance on use: only when one action is clearly the most common (Visma, ServiceNow). Goes into the docs page.

## 3. States and edge cases seen

- Disabled: whole control (Ant, Fluent v9, Spectrum) vs primary only (Fluent v8 `primaryDisabled`, PrimeNG). Both are needed: "Send" is disabled on an empty draft while "Save as template" is not.
- Loading: spinner on the primary only; menu stays usable.
- Icon-only toggle primary with a status (Teams mic muted, WinUI `ToggleSplitButton`).
- Destructive (Polaris), per-item danger (Ant): `c2-menu-item destructive` already covers items.
- Placement: Fluent `below-end`, Ant `autoAdjustOverflow`, Lightning `menu-alignment="auto"`. `c2-overlay` flips through floating-ui.
- Touch: Fluent's 24px minimum is too small; the caret needs ≥44px hit area on coarse pointers.
- Forced colours: the divider must use `CanvasText`/`ButtonText`, not a translucent white.

## 4. What c2 already has

| Need                         | Existing piece                                                                                                                                                                                                                                                                   |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Menu, rows, keyboard, flip   | `c2-menu` + `c2-menu-item` (`type="radio"`, `checked`, `description`/`prefix-icon`/`shortcut` slots, `destructive`, `<hr>`, `<h1>`–`<h6>` headings), `menu-select` (bubbles, composed, cancelable), floating-ui via `c2-overlay`, focus return to the trigger.                   |
| Anchor ≠ trigger             | `c2-menu` keeps them apart already: `anchor` (element) positions the surface and sets its minimum width; the slotted `trigger` gets `aria-haspopup`/`aria-expanded` and focus back (`menu.ts` `resolveAnchor`, `syncTriggerAria`, `returnFocus`). No change to `c2-menu` needed. |
| Re-slotting items            | `c2-menu` reads rows with `assignedElements({ flatten: true })`, so `<slot name="menu">` inside the split button's shadow root reaches it.                                                                                                                                       |
| Joined radii / divider       | `c2-button-group` (`--c2-button-group--gap` driving inner radius `min(radius, gap*10000)`, divider via `box-shadow`). Same technique, local to the component.                                                                                                                    |
| Form submit, running spinner | `c2-button` (`formAssociated`, `requestSubmit`, `running`, `running-icon`).                                                                                                                                                                                                      |
| Localised text               | `defineMessages` / `LocalizeController` from `@c2n/core/localize.js` (`c2-select`, `c2-view-options`).                                                                                                                                                                           |

No component in the repo wraps button + menu as one control (`grep split-button|menu-button` → only the roadmap row).
