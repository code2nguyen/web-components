The last cards wire properties from script: the renderers, a `dataSource` and a translation.

The renderer card draws each column's samples and each preview cell from script. The component keeps the cell, its error tint and its message:

```ts tag=CodeBlock
import { html } from 'lit'
import type { ImportMapper } from '@c2n/components/import-mapper'

const money = new Intl.NumberFormat('en', { style: 'currency', currency: 'USD' })
mapper.renderSamples = ({ values }) => html`<span>${values.length} values, e.g. <b>${values[0]}</b></span>`
mapper.renderCell = ({ value, field, error }) =>
  field.key === 'amount' && !error ? html`<span style="color:${Number(value) < 0 ? '#b91c1c' : '#15803d'}">${money.format(Number(value))}</span>` : value
```

The data source card reads 240 orders a page at a time, after a short delay, as a server would:

```ts tag=CodeBlock
mapper.columns = ['Order', 'Customer', 'Total']
mapper.dataSource = {
  async getRows({ start, count }) {
    const { rows, total } = await fetch(`/imports/42/rows?start=${start}&count=${count}`).then((r) => r.json())
    return { rows, total } // rows: arrays of cells, or records keyed by header
  },
}
```
