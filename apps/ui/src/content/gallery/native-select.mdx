## Field

The field is the `--c2-native-select--*` family, with `__hover`, `__focus` and `__error` states. The picker itself is
the browser's: only its options' colours follow the field, in the browsers that colour it.

</c2-native-select>

## Icons

`prefix-icon` takes an inline SVG or an icon element, sized by `--c2-native-select__icon--size`; the select keeps that
room free so the text never runs under it. `suffix-icon` replaces the chevron. Clicks pass through both to the select.

<GalleryGrid>

```html tag=MdxCodeBlock,label=Prefix icon
<style>
  .prefix-icon {
    width: 210px;
  }
</style>
<c2-native-select aria-label="Language" value="en" class="prefix-icon">
  <svg slot="prefix-icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
    <circle cx="12" cy="12" r="10"></circle>
    <line x1="2" y1="12" x2="22" y2="12"></line>
    <path d="M12 2a15.3 15.3 0 0 1 4 10 15.3 15.3 0 0 1-4 10 15.3 15.3 0 0 1-4-10 15.3 15.3 0 0 1 4-10z"></path>
  </svg>
  <option value="en">English</option>
  <option value="fr">Français</option>
  <option value="vi">Tiếng Việt</option>
</c2-native-select>
```

## Options

Options are written as `<option>` and `<optgroup>` children, or given as `options`: JSON in markup or an array from
script. The children win when both are given.

<GalleryGrid>

```html tag=MdxCodeBlock,label=Option groups
<style>
  .groups {
    width: 220px;
  }
</style>
<c2-native-select aria-label="Time zone" value="Asia/Tokyo" class="groups">
  <optgroup label="Europe">
    <option value="Europe/London">London</option>
    <option value="Europe/Paris">Paris</option>
  </optgroup>
  <optgroup label="Asia">
    <option value="Asia/Ho_Chi_Minh">Ho Chi Minh City</option>
    <option value="Asia/Tokyo">Tokyo</option>
  </optgroup>
  <optgroup label="Retired" disabled>
    <option value="Asia/Saigon">Saigon</option>
  </optgroup>
</c2-native-select>
```

```html tag=MdxCodeBlock,label=Options as JSON
<style>
  .json-options {
    width: 220px;
  }
</style>
<c2-native-select
  aria-label="Plan"
  value="team"
  class="json-options"
  options='[{"value":"free","label":"Free"},{"value":"team","label":"Team · $29"},{"value":"scale","label":"Scale · $99"},{"value":"enterprise","label":"Enterprise (contact us)","disabled":true}]'
></c2-native-select>
```

```html tag=MdxCodeBlock,label=Options loaded later
<style>
  .later {
    width: 200px;
  }
</style>
<c2-native-select aria-label="Country" value="JP" class="later" data-native-select-example="later"></c2-native-select>
```

</GalleryGrid>

The last card's options arrive from script after a delay, as a fetch would; the `value` set in markup waits for them:

```ts tag=CodeBlock
const country = document.querySelector('c2-native-select')!
country.options = await fetchCountries() // [{ value: 'JP', label: 'Japan' }, …]
```

Sending the French form with no size shows the browser's bubble with the select's own message, translated by the page
and following the form's `lang`:

```ts tag=CodeBlock
import { addTranslations } from '@c2n/core/localize.js'

addTranslations({ fr: { 'native-select': { valueMissing: 'Veuillez sélectionner une option.' } } })
```
