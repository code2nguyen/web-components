`c2-aging-table` is [`c2-pivot-table`](/web-components/components/pivot-table) shaped for an accounts receivable or
payable aging report: each row is a customer or a vendor, each column a bucket of days past due counted to an as-of
date, and every cell the open amount in it. Grouping, subtotals, sorting, the heatmap, drill-down and CSV export are
the pivot table's and work the same.

## Import

```typescript tag=CodeBlock
import '@c2n/components/pivot-table/aging-table'
```

The entry registers `c2-aging-table` and `c2-pivot-table`, and the menu the field list uses.

### Items and dates

`data` is a flat list of open items, one per invoice or bill. Each has the date it ages from in `date-field` (`dueDate`
by default; a `YYYY-MM-DD` text, a timestamp or a `Date`) and an amount. The days past due are the whole days from
that date to `as-of`; an item due on the as-of day or later is Current. Leave `as-of` empty to age to today. Point
`date-field` at the invoice date (`date-field="invoiceDate"`) to age from issue instead of from the due date.

`rows` groups the items, `customer` by default (`vendor` for payables; `region;customer` nests them, with a subtotal
per region), and `values` sums their amount, `[{ "field": "amount" }]` by default. Give the value a `format` for a
currency. The columns are always the buckets, so `columns` has no effect, and with `configurable` the field list
changes the rows and values only.

### Buckets

`buckets` lists the last day of each bucket past due: `30;60;90` (the default) gives Current, 1–30, 31–60, 61–90 and
Over 90, and `15;30;45;60` gives finer columns for a collections team. Every bucket shows even when nothing falls in
it, so two reports always line up, and an item with no date shows under a "No date" column. The grand total row and
column add up each bucket and each customer.

### Overdue amounts

A value past due carries the class `overdue`, and one in the last bucket `oldest` too. Colour them with
`--c2-aging-table__overdue--color`, `--c2-aging-table__oldest--color` (the error red by default) and
`--c2-aging-table__oldest--font-weight`. With `heatmap`, the cells are tinted by amount as in the pivot table.

### As-of line and drill-down

The line above the grid names the as-of date in the reader's language. Replace it through the `as-of` slot, for
example with a date input that sets `as-of`. `cell-click` gives the records behind a cell, with the bucket in
`columnPath` as its key (`0` for Current, `1-30`, …, `91+`, `(blank)` for no date), so a click can list the invoices.

```ts tag=CodeBlock
aging.addEventListener('cell-click', ({ detail }) => {
  const [bucket] = detail.columnPath // '31-60'
  showInvoices(detail.records) // the items of `data`, unchanged
})
```

### Keyboard and screen readers

The grid is the pivot table's `treegrid`: the arrow keys move between cells, Left and Right close and open a group,
Enter on a value cell fires `cell-click`, and each bucket header sorts the rows by its amounts. The grid is named
"Aging table" unless `label` names it, and the as-of line is read before it.
