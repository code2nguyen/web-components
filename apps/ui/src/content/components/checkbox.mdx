`c2-checkbox` wraps a native `<input type="checkbox">`, so `checked`, `indeterminate`, `disabled`, `name` and the `change` event behave exactly like the built-in control. The visible box sits centred in a square touch target whose size is `--c2-checkbox__state-layer--size`; that same square is the hover layer, transparent by default. Set a `state-layer__hover__*--color` to tint it, or shrink it to the box size for a compact inline checkbox. Keyboard focus draws a ring around the box. The three marks are slots that take an inline SVG, a `c2-feather-*` icon or a `c2-mat-icon` ligature.

## Installation

```bash tag=CodeBlock
npm install @c2n/checkbox
```
