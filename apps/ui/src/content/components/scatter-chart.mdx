This view pairs Apple R&D expense with annual revenue from the public [SEC Company Facts data](https://data.sec.gov/api/xbrl/companyfacts/CIK0000320193.json). It answers a real question a time-series chart cannot: whether larger investment years also occupy a different revenue range.

## Installation

```bash tag=CodeBlock
npm install @c2n/chart echarts
```

## Usage

```html tag=UsageBlock,package=@c2n/chart
<style>
  .finance-scatter,
  .finance-scatter-live {
    display: grid;
    width: 100%;

  }

    display: flex;

  }
</style>

<div data-label="Default">
  <c2-scatter-chart x-field="rd" data='[{"year":2021,"rd":21.914,"revenue":365.817},{"year":2022,"rd":26.251,"revenue":394.328},{"year":2023,"rd":29.915,"revenue":383.285},{"year":2024,"rd":31.37,"revenue":391.035},{"year":2025,"rd":34.55,"revenue":416.161}]'>

</div>

<div data-label="Custom legend + tooltip" data-finance-demo>
  <div class="finance-scatter">
    <c2-scatter-chart id="scatter-investment" x-field="rd" symbol-size="14" data='[{"year":2021,"rd":21.914,"revenue":365.817},{"year":2022,"rd":26.251,"revenue":394.328},{"year":2023,"rd":29.915,"revenue":383.285},{"year":2024,"rd":31.37,"revenue":391.035},{"year":2025,"rd":34.55,"revenue":416.161}]'>

<div data-label="Realtime replay" data-advanced-realtime>
  <div class="finance-scatter-live">
    <c2-scatter-chart x-field="rd" symbol-size="13" data='[{"year":2021,"rd":21.914,"revenue":365.817}]'>

  </div>
</div>
```

`x-field` supplies the horizontal measure and each `c2-chart-series` supplies a vertical measure. `symbol`, `symbol-size`, `large` and `large-threshold` tune the marks and opt into ECharts' high-volume rendering path. The replay seeds its first observation, waits for `chart-ready`, then interpolates each new point from the preceding year; a streaming UI should use the same readiness boundary before starting a high-frequency feed.
