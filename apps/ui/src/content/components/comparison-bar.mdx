import { ComparisonBar } from '@c2n/comparison-bar'

`c2-comparison-bar` splits its width between two amounts: `start-value` on the start side and `end-value` on the end side, in any unit. The bar computes each side's share, and `show-value` prints it as a percentage at that end; the two shares always add up to 100. `precision` sets the fraction digits (2 by default) and `locale` the number format. `start-label` and `end-label` name the sides for assistive technology, which reads the whole bar as one image ("Bid 22.43%, Ask 77.57%"), and the `start` and `end` slots replace the printed text when you want counts instead of percentages.

## Installation

```bash tag=CodeBlock
npm install @c2n/comparison-bar
```

## Usage

```html tag=UsageBlock,package=@c2n/comparison-bar
<style>
  .stack {
    display: grid;
    gap: 16px;
    width: 320px;
    max-width: 100%;
  }
  .order-book {
    width: 320px;
    max-width: 100%;
    padding: 16px;
    border-radius: 8px;
    background: #1e2329;
    --c2-comparison-bar__start-segment--background-color: #2ebd85;
    --c2-comparison-bar__start-value--color: #2ebd85;
    --c2-comparison-bar__end-segment--background-color: #f6465d;
    --c2-comparison-bar__end-value--color: #f6465d;
  }
  .thick {
    --c2-comparison-bar--height: 12px;
    --c2-comparison-bar--border-radius: 4px;
    --c2-comparison-bar__track--gap: 2px;
  }
</style>
<div data-label="Default">
  <div class="stack">
    <c2-comparison-bar start-value="22.43" end-value="77.57" start-label="Bid" end-label="Ask"></c2-comparison-bar>
    <c2-comparison-bar start-value="2243" end-value="7757" start-label="Bid" end-label="Ask" show-value></c2-comparison-bar>
  </div>
</div>
<div data-label="Precision and locale">
  <div class="stack">
    <c2-comparison-bar start-value="3" end-value="1" precision="0" show-value></c2-comparison-bar>
    <c2-comparison-bar start-value="1" end-value="2" precision="1" locale="de-DE" show-value></c2-comparison-bar>
  </div>
</div>
<div data-label="Custom text">
  <div class="stack">
    <c2-comparison-bar class="thick" start-value="12" end-value="8" start-label="Yes" end-label="No">
      <span slot="start">Yes 12</span>
      <span slot="end">8 No</span>
    </c2-comparison-bar>
  </div>
</div>
<div data-label="Order book">
  <div class="order-book">
    <c2-comparison-bar start-value="22.43" end-value="77.57" locale="de-DE" start-label="Bid" end-label="Ask" show-value></c2-comparison-bar>
  </div>
</div>
```

Update `start-value` and `end-value` as the amounts change and the segments animate to their new widths. Negative or missing amounts count as zero; a side with no share collapses entirely, and while neither side has an amount the bar splits evenly. The printed percentages are hidden from screen readers because the bar's accessible name already carries them.

`--c2-comparison-bar__start-segment--background-color` and `--c2-comparison-bar__end-segment--background-color` colour the two segments, with matching `__start-value--color` / `__end-value--color` for the text. `--c2-comparison-bar--height`, `--c2-comparison-bar--border-radius` and `--c2-comparison-bar__track--gap` shape the bar itself.
