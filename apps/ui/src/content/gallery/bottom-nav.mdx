## Looks

Every look is a set of CSS variables on the bar. The item variables (`--c2-bottom-nav-item__*`) inherit, so one class on `c2-bottom-nav` styles the bar and all of its items. The indicator and the top line carry most of the difference; set the indicator to `transparent` for a tint-only bar, and keep a filled `current-icon` so the current item is not marked by colour alone.
