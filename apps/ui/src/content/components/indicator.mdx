`c2-indicator` wraps any element and pins a solid marker to it: an unread count on an inbox button, a presence dot on an avatar, a "new" flag on a tab. Without a `count` and with nothing in the `label` slot it is a dot; a `count` is clamped at `max` (`99+`) and a count of `0` hides it unless `show-zero` is set. `position` picks one of eight spots in logical terms, so `top-end` follows the writing direction, and `invisible` scales the marker out once its notifications are read. Six `tone`s carry meaning, each a background/text variable pair.

## Import

```typescript tag=CodeBlock
import '@c2n/components/indicator'
```

The examples use icons from the separate `@c2n/feather-icons` package: `npm install @c2n/feather-icons`.

## Usage

    --c2-indicator--offset-x: 14.6%;
    --c2-indicator--offset-y: 14.6%;

    --c2-avatar--size: 40px;
  }
  .box {
    display: inline-block;
    width: 72px;
    height: 48px;
    border-radius: 8px;
    border: 1px dashed var(--c2-theme--color-outline, #bcbcc6);
  }
  .label-icon {
    --c2-indicator__icon--size: 10px;
  }

  </c2-indicator>

The wrapped element keeps its own role and focus; the marker ignores the pointer, so a click on it reaches the element underneath. A bare `3` read after a button means little, so give `accessible-label` a phrase such as `{count} unread messages`: `{count}` becomes the displayed count and the phrase replaces the visible marker in the accessibility tree. A dot has no text, so without `accessible-label` it is not announced at all.

The marker is centred on the edge or corner of the wrapped element's box, which suits buttons and cards. For a round target such as an avatar or icon button, set `--c2-indicator--offset-x` and `--c2-indicator--offset-y` to `14.6%` to move it onto the circle. `--c2-indicator--border` draws a ring in the page background colour; set it to `none` on a coloured surface.

`c2-badge` can also pin a count to a corner through its `anchor` slot. Reach for `c2-badge` when the mark is a tinted label in its own right, and for `c2-indicator` when it is a solid notification marker on another element, needs a centre or middle position, or has to follow a right-to-left layout.
