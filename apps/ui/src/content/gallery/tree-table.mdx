`c2-tree-table` is `c2-table` with nested rows. Every card of the table gallery works here too; these are the ones that need the rows nested.

## Tree rows

`children-field` reads each row's child rows from a field of its own, nested to any depth, and turns the grid into a `treegrid`: a parent is an ordinary row with a chevron, indented by level in the first column (or the one marked `group-column`). A column with `rollup` shows in a parent the aggregate of the leaves under it, so the totals of a chart of accounts or a bill of materials need no precomputing, and a sort orders each level by those figures. With `selection="multiple"` a parent selects the rows under it and follows its children.

The regions in "Children loaded on open" get their countries from `loadChildren` the first time they open, after a short delay that stands in for the network; their field holds `true` until then, and the chevron turns into a spinner while they load.

```ts tag=CodeBlock
table.loadChildren = async ({ key }) => {
  const response = await fetch(`/api/regions/${key}/countries`)
  return response.json() // [{ id: 'de', region: 'Germany', stores: 12, revenue: 1480000 }, …]
}
```

## Requirements

## Goals

A goal tree is a tree with a progress column: `rollup="avg"` gives each objective the mean progress of its key results, and a `renderCell` draws it as a `c2-progress` bar. The status is the table's `format="status"`.

```ts tag=CodeBlock
progressColumn.renderCell = ({ row, value }) => {
  const bar = document.createElement('c2-progress')
  bar.setAttribute('value', String(Math.round(Number(value))))
  bar.setAttribute('show-value', '')
  bar.setAttribute('label', `${row.goal}: progress`)
  return bar
}
```
