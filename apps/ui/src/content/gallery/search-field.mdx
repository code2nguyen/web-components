## Presets

The box is one set of variables (`--c2-search-field--border`, `--c2-search-field--background`, `--c2-search-field--border-radius`, `--c2-search-field--min-height`), with `--c2-search-field__hover--*` and `--c2-search-field__focus--*` states on top. The `--c2-search-field__shortcut--*` variables style the key hint, and the `--c2-search-field__panel--*` and `--c2-search-field__option--*` variables the recent-searches list.
