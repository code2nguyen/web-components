## Presets

Status panels work best with one clear message and a small number of useful next steps. The media, surface and content regions can be themed independently without changing the semantic structure.

Classes style assigned media, text, and buttons directly. The same-named public parts style the panel-owned regions and built-in fallbacks; for example, `.recovery::part(actions) { justify-content: flex-start; }`.
