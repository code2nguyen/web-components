## Presets

Curated looks for `c2-list`. Open any card in the studio to start from it. The container is `--c2-list--*` (background, padding, borders, radius, shadow, gap, max-height), group headings and dividers are `--c2-list__heading--*` / `--c2-list__divider--*`, and the rows inherit any `--c2-list-item--*` variable set on the list.
