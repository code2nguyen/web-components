The cards that start and finish the bar call its methods; the French card is named "Chargement de la page" once the application supplies the text:

```ts tag=CodeBlock
import { addTranslations } from '@c2n/core/localize.js'

addTranslations({ fr: { 'navigation-progress': { loading: 'Chargement de la page' } } })

const bar = document.querySelector('c2-navigation-progress')!
bar.start() // shows the bar and trickles it forward
bar.done() // fills it and fades it out
```
