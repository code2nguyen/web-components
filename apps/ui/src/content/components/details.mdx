`c2-details` wraps a native `<details>` / `<summary>` pair, so keyboard access, screen-reader semantics and find-in-page auto-expand come from the browser. Give panels the same `name` and they form an exclusive accordion: opening one closes the others. The header is the `title` slot (or the `label` attribute) plus an optional `header-content` row that stays visible when collapsed; buttons and links placed there work without toggling the panel. `title-not-clickable` limits toggling to the chevron, `disabled` blocks it. Open and close slide the content smoothly in every browser (`--c2-details--transition-duration` controls the length, reduced motion disables it), and `expanded` mirrors the native `open` state; listen for `toggle` on the element. Content rendered only once the panel opens (in a `toggle` listener, by a framework) still slides open: the panel follows content that grows while it opens. `headless` turns the panel into a collapse: the content alone, with no summary and no frame, opened by a control elsewhere on the page. A `c2-button` (or a native button) with `commandfor` and `command="--toggle"` (or `--open`, `--close`) needs no script, and the panel keeps its `aria-expanded` in step; any other control sets `expanded` or calls `toggle()`. Closed content stays findable by find-in-page, which opens the panel.

## Import

```typescript tag=CodeBlock
import '@c2n/components/details'
```

## Usage

```html tag=UsageBlock,package=@c2n/details
<style>
  .demo {
    width: 300px;
  }
  .demo p {
    margin: 0;
    font-size: 13px;
    line-height: 1.5;
    color: color-mix(in srgb, var(--c2-theme--color-on-surface, #18181b) 74%, var(--c2-theme--color-surface, #ffffff));
  }
  .collapse-trigger {
    --c2-button__container--height: 30px;
    --c2-button__container--padding-left: 8px;
    --c2-button__container--padding-right: 8px;
    --c2-button__container--font-size: 13px;
    --c2-button__container--background-color: transparent;
    --c2-button__container--color: var(--c2-theme--color-primary, #0265dc);
    --c2-button__container__hover--background-color: var(--c2-theme--color-primary-container, #edf1fe);
    --c2-button__container__hover--color: var(--c2-theme--color-primary, #0265dc);
    --c2-button__container__active--background-color: var(--c2-theme--color-primary-container, #edf1fe);
    margin-left: -8px;
  }
  .stack {
    display: grid;
    gap: 8px;
    width: 300px;
  }

<div data-label="Default">
  <c2-details class="demo" label="What is included?">
    <p>Everything in the free plan plus unlimited projects and priority support.</p>
  </c2-details>
</div>
<div data-label="Header content">
  <c2-details class="demo" expanded client:load>
    <span slot="title">Billing</span>
    <span slot="header-content">Next invoice on 1 Oct</span>
    <p>Visa ending 4242. Invoices are sent to billing@example.com.</p>
    <c2-button slot="header-content" style="margin-left: 8px; --c2-button__container--font-size: 12px">Update card</c2-button>
  </c2-details>
</div>
<div data-label="Accordion">
  <div class="stack">
    <c2-details name="faq" label="Can I cancel anytime?"><p>Yes. Your plan stays active until the end of the period.</p></c2-details>
    <c2-details name="faq" label="Do you offer refunds?"><p>Within 14 days, no questions asked.</p></c2-details>
    <c2-details name="faq" label="Is there a student discount?"><p>50% off with a valid student email.</p></c2-details>
  </div>
</div>
<div data-label="Headless collapse">
  <div class="demo">
    <c2-button class="collapse-trigger" commandfor="usage-collapse" command="--toggle" aria-controls="usage-collapse" aria-expanded="false">Show delivery details</c2-button>
    <c2-details id="usage-collapse" headless><p>Orders placed before 2 pm ship the same day. Weekend orders ship on Monday.</p></c2-details>
  </div>
</div>
<div data-label="Icon only toggles">
  <c2-details class="demo" title-not-clickable label="Only the chevron toggles"><p>Clicks on the title are ignored.</p></c2-details>
```
