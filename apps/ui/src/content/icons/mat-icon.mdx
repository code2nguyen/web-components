# Mat Icon

`c2-mat-icon` is a simple wrapper for Material Icon font component.

## Installation

```bash tag=CodeBlock
npm install @c2n/mat-icon
```

## Import

```typescript tag=CodeBlock
import '@c2n/mat-icon'
```

## Examples

```html tag=MdxCodeBlock,compact=true
<c2-mat-icon>home</c2-mat-icon>
```

Use the sliders button on the example, or select any icon in the gallery, to open that icon directly in the configuration studio.
