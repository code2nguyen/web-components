The "Own quality rules" card asks for a brighter picture than the built-in rule, and keeps the others:

```ts tag=CodeBlock
import { assessFrame } from '@c2n/components/camera-capture'

camera.assessFrame = (metrics, context) => (metrics.brightness < 150 ? 'dark' : assessFrame(metrics, context))
```

A pretend camera for a demo or a test is a canvas: `captureStream()` turns what it draws into a video track.

```ts tag=CodeBlock
import type { CameraStreamSource } from '@c2n/components/camera-capture'

const canvas = document.createElement('canvas')
canvas.width = 640
canvas.height = 480
setInterval(() => drawScene(canvas.getContext('2d')!), 1000 / 15)

const demoCamera: CameraStreamSource = async () => canvas.captureStream(15)
document.querySelector('c2-camera-capture')!.streamSource = demoCamera
```
