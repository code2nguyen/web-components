## Presets

`--c2-description-list__grid--*` decides the columns: the most there may be, the narrowest one may get, and the gaps. `--c2-description-item__label--width` switches a label from above its value to beside it, and the `__container`, `__label` and `__value` parts of the item carry the dividers, padding and type. Set item variables on the list and every item picks them up. Items with several `c2-description-value` children line up in columns named by `value-labels`; `--c2-description-item__value-column--*` sizes them, and below the minimum column width the values stack with their column names. `--c2-description-list__value-header--*` styles the column names (`--display: none` removes the row) and `--c2-description-value__caption--*` the names beside stacked values.
