## Presets

Curated looks for `c2-swipe-action`. Open any card in the studio to start from it. The `__actions--*` variables decide
how the actions sit: `padding: 0`, `gap: 0px` and `align-items: stretch` turn buttons into full-bleed blocks, while the
defaults keep them as buttons at their own height. `__content--*` styles the sliding row and `__container--*` what
shows behind it. Each card is opened so the actions are visible; swipe it to try the gesture.
