## Drops from another list

A list with `drop-kind` takes rows dropped from outside it. The source writes them with `writeItemPayload` from
`@c2n/core/controllers/drop-zone.js` under the same kind; the list lights up while they are over it (red for another
kind), fires `item-drop` with the row to insert before, and announces how many were added. The page adds the rows. Drag
a task by its handle to the other list.

```ts tag=CodeBlock
import { writeItemPayload } from '@c2n/core/controllers/drop-zone.js'

// The source: a handle in each row writes the row under the list's drop-kind.
handle.draggable = true
handle.addEventListener('pointerdown', (event) => event.stopPropagation()) // keep the list's own reorder off it
handle.addEventListener('dragstart', (event) => writeItemPayload(event.dataTransfer!, 'task', [{ id: row.dataset.reorderKey, label: 'Send the invoice' }]))

// The target hands the place over; the page adds (or moves) the row.
today.addEventListener('item-drop', ({ detail }) => {
  for (const task of detail.items) today.insertBefore(rowFor(task), detail.before)
})
```

<ReorderListExamplesRuntime />

`ranked` draws each row's position; `renderRank` replaces the number with your own content, and `name` makes the list a form control that submits the item keys in their displayed order. The `value` attribute (keys separated by `;`) sets the order it starts in, which the Ranking form card uses for a saved answer and which a form reset returns to:

```ts tag=CodeBlock
import { html } from 'lit'
import type { ReorderList } from '@c2n/components/reorder-list'

const list = document.querySelector<ReorderList>('c2-reorder-list')!
const ordinals = new Intl.PluralRules('en', { type: 'ordinal' })
const suffixes: Record<string, string> = { one: 'st', two: 'nd', few: 'rd', other: 'th' }
list.renderRank = ({ rank }) => html`${rank}<sup>${suffixes[ordinals.select(rank)]}</sup>`

// <form><c2-reorder-list name="commute" value="train;bike" editable ranked>…</c2-reorder-list></form>
list.addEventListener('input', () => {
  const ranking = new FormData(list.closest('form')!).getAll('commute') // ['train', 'bike', …]
})
```
