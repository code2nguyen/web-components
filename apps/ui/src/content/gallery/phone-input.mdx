## Presets

The box is one set of variables (`--c2-phone-input--border`, `--c2-phone-input--background`, `--c2-phone-input--border-radius`, `--c2-phone-input--min-height`) with `__hover--*`, `__focus--*` and `__invalid--border` on top. The `--c2-phone-input__country--*` variables style the country button and `__divider--border` the line after it; `__flag--display: none` leaves only the calling code. The `__panel--*`, `__search--*` and `__option--*` variables style the country list.
