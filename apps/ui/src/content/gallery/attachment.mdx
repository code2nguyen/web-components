## Groups

Groups provide spacing and collection semantics without changing the attachments themselves. Use the default list for narrow surfaces and `layout="grid"` when the available width should determine the column count.

<GalleryGrid>

```html tag=MdxCodeBlock,label=List,description=Related file rows with list semantics,useWhen=Attachments should span the available width
<c2-attachment-group>
  <c2-attachment name="contract.pdf" type="PDF" size="820 KB" status="complete" removable></c2-attachment>
  <c2-attachment name="appendix.xlsx" type="Spreadsheet" size="1.2 MB" removable></c2-attachment>
</c2-attachment-group>
```

```html tag=MdxCodeBlock,label=Responsive grid,description=Responsive attachment tiles sized by the available width,useWhen=Several visual files should scan as a gallery
<style>
  .attachment-grid {
    --c2-attachment-group--min-column-width: 190px;
  }
</style>
<c2-attachment-group class="attachment-grid" layout="grid">
  <c2-attachment name="cover.jpg" type="JPG" size="640 KB" src="/web-components/chat.avif"></c2-attachment>
  <c2-attachment name="copy.md" type="Markdown" size="8 KB"></c2-attachment>
  <c2-attachment name="sources.zip" type="ZIP" size="4.3 MB"></c2-attachment>
</c2-attachment-group>
```

</GalleryGrid>

## Mixed media

The mixed layout follows the reference composition: visual files form a tile row, while ordinary attachments and upload states span the full width below it.

