`c2-banner` shows a message that stays on the page until the user acts on it or the condition goes away, unlike a
toast, which floats and expires. `variant` picks the colours and the default icon, and also the announcement:
`warning` and `error` are exposed as alerts, the others as status messages. Put the text in `message` or the default
slot, add buttons or links to the `actions` slot, and set `dismissible` for a close button.

## Import

```typescript tag=CodeBlock
import '@c2n/components/banner'
```

## Position

By default a banner sits in the page flow where you place it. Set `position` to pin it to an edge of the viewport:

- `top` is **sticky**: the banner keeps its place in the flow and sticks to the top of its scroll container as the page
  scrolls, so it never covers content. Use it for app-wide notices placed first in the page.
- `bottom` is **fixed**: the banner floats over the content at the bottom of the viewport, as a cookie-consent bar does.
  Give the page bottom padding at least as tall as the banner so the last content stays reachable.

A pinned banner spans the full width with square corners and keeps a border on its inner edge only.
`--c2-banner--offset` moves it away from the edge (below a fixed header, for example) and `--c2-banner--z-index`
sets its stacking order. Scroll the page below: the banner stays on top of it.

## Dismissing

The close button fires a cancelable `banner-close` event and then hides the banner (`hidden`). Call
`event.preventDefault()` to keep it, for example until a request that records the dismissal succeeds, and
`show()` to bring a dismissed banner back.

```ts tag=CodeBlock
const banner = document.querySelector('c2-banner')!
banner.addEventListener('banner-close', () => localStorage.setItem('maintenance-banner', 'dismissed'))
```
