`c2-bottom-nav` is the tab bar of a mobile app: three to five `c2-bottom-nav-item` destinations, each an icon (`icon` slot) over a short label, with an optional `count` or `dot` badge. It is a navigation landmark of plain links (items with an `href`) or buttons, named "Main" unless you give the host an `aria-label`. The current item is announced with `aria-current="page"` and marked by more than colour: an indicator behind the icon, and the `current-icon` slot when you give a filled variant. A badge is read as part of the item's name ("Payments, 3 new").

Set `value` to the value of the item being shown, or mark that item `current`. Activating another item fires a cancelable `item-select` (cancel it to keep the user on a screen with unsaved changes; a link is not followed), then updates `value` and fires `change`. Activating the current item again fires `reselect`: scroll back to the top there.

The host is `position: sticky` at the bottom, so as the last element of the page it stays on screen without covering the end of the content, and the bar is padded by `env(safe-area-inset-bottom)` for the phone's home indicator (add `viewport-fit=cover` to the viewport meta). `hide-on-scroll` slides it away while the page scrolls down and brings it back on scroll up, at the top or when focus moves into it; `scroll-target` names a scrolling element other than the window. `label-visibility` shows every label (`labeled`, the default), only the current one (`selected`), none (`unlabeled`), or all of them up to three items and only the current one from four (`auto`). Hidden labels remain the items' accessible names.

Use it for the top-level sections of a phone layout. On wider screens, switch to `c2-side-nav` with a media query, or lay the items out in a row with `--c2-bottom-nav-item--flex-direction: row`. Avoid disabling or hiding items, and keep badges for what needs attention.

## Import

```typescript tag=CodeBlock
import '@c2n/components/bottom-nav'
```

Importing `@c2n/components/bottom-nav` registers `c2-bottom-nav-item` too. The examples use icons from the separate `@c2n/phosphor-icons` package: `npm install @c2n/phosphor-icons`.

```javascript tag=CodeBlock
const nav = document.querySelector('c2-bottom-nav')
nav.addEventListener('item-select', (event) => {
  if (hasUnsavedChanges()) event.preventDefault() // stay, and the link is not followed
})
nav.addEventListener('change', () => router.navigate(nav.value))
nav.addEventListener('reselect', () => window.scrollTo({ top: 0, behavior: 'smooth' }))
```
