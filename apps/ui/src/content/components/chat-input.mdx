`c2-chat-input` is an auto-growing message composer. Enter fires `submit-message` and clears the message; Alt+Enter inserts a newline. It is also a form-associated textarea: `name` contributes its current text to `FormData(form)`, while `required`, `minlength`, `maxlength`, fieldset disabling, form reset and the standard validation methods follow native form behavior.

## Installation

```bash tag=CodeBlock
npm install @c2n/chat-input
```

## Usage

```html tag=UsageBlock,package=@c2n/chat-input
<div data-label="Default">
  <c2-chat-input client:only="lit"></c2-chat-input>
</div>
```
