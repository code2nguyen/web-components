## Single and multiple dates

`mode="single"` picks one date into `value`; `mode="multiple"` toggles any number of dates. `marked` puts a dot under
the days that carry something, and `renderDay` draws content of your own under the number.

The fares card sets `renderDay` from script; a renderer can return a string, a node or a Lit template:

```ts tag=CodeBlock
import type { DateSelector } from '@c2n/components/date-selector'

const fares: Record<string, number> = { '2026-09-15': 129, '2026-09-16': 98 /* … */ }
const calendar = document.querySelector<DateSelector>('.fare-calendar')!
calendar.renderDay = ({ date, disabled }) => (disabled || !(date in fares) ? undefined : `$${fares[date]}`)
```

The closed-days card names its holidays in `disabled-dates` (each reason is read with the day) and closes every Sunday
by rule with `isDateDisabled`; the arrow keys step over both:

```ts tag=CodeBlock
const calendar = document.querySelector<DateSelector>('c2-date-selector')!
calendar.isDateDisabled = (date) => new Date(`${date}T12:00:00`).getDay() === 0
```

## Comparing two periods

`compare-from` and `compare-to` draw a comparison range as a band under its days, beside the range itself.
`compare="previous-period"` and `compare="previous-year"` derive it from the range; `editing="compare"` lets the user
pick it on the grid. The `footer` slot holds the app's own "Compare to" control.

The toggle card sets `compare` from the select in its footer. A footer control's own `input` and `change` stop at
the footer, so the selector's `change` is always its own and the select is listened to directly. The French card's
text comes from the app, which adds the language once:

```ts tag=CodeBlock
import type { DateSelector } from '@c2n/components/date-selector'
import { addTranslations } from '@c2n/core/localize.js'

addTranslations({ fr: { 'date-selector': { chooseRange: 'Choisir une période', inComparison: 'Dans la période de comparaison' /* … */ } } })

const period = document.querySelector<DateSelector>('.compare-toggle')!
period.addEventListener('change', ({ detail }) => report(detail.from, detail.to, detail.compareFrom, detail.compareTo))
period.querySelector('c2-select')!.addEventListener('change', (event) => {
  const compare = (event.currentTarget as HTMLElement & { value: string[] }).value[0]
  if (compare === 'previous-period' || compare === 'previous-year') period.compare = compare
  else Object.assign(period, { compare: '', compareFrom: '', compareTo: '' })
})
```
