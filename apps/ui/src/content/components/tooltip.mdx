`c2-tooltip` describes the element it sits in: drop it inside a button and the button is the target, or point it at another element with `for="<id>"`. It shows after `delay` milliseconds on hover or focus and hides on leave, blur, press or Escape. The text is the slotted content, or the target's `data-tooltip` attribute when the slot is empty. It renders as a `popover` in the top layer, so it is never clipped by `overflow: hidden` or scrolling ancestors, and floating-ui flips the preferred `placement` when there is no room (the side in use is reflected as `current-placement`). The tooltip has `role="tooltip"` and the target gets `aria-describedby`, so screen readers announce it. `c2-icon-button` uses it for its `tooltip` attribute.

## Installation

```bash tag=CodeBlock
npm install @c2n/tooltip
```
