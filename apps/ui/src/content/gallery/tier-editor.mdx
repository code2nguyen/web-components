checks on the bounds, a read-only rate card, a form with fixed bounds, a restyled preview, a preview drawn by the app, a
pricing switch in the `actions` slot and tiers in French.

The preview drawn by the app and the pricing switch are wired from script:

```ts tag=CodeBlock
import '@c2n/components/key-value-editor/tier-editor'

const editor = document.querySelector('c2-tier-editor')!
editor.renderPreview = ({ quote, tiers, format, formatTotal }) => {
  if (quote.total === null) return 'Not priced'
  const tier = tiers[quote.tier]
  return `${format(quote.quantity)} API calls this month: ${formatTotal(quote.total)} (tier ${quote.tier + 1} from ${format(tier?.from ?? 0)})`
}

// A c2-button-group in the actions slot switches between graduated and volume pricing.
editor.querySelector('c2-button-group')!.addEventListener('change', (event) => {
  editor.pricing = event.detail.value === 'volume' ? 'volume' : 'graduated'
})
```
