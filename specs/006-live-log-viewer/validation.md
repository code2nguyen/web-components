# Virtual Log Content Viewer validation

Date: 2026-09-26. This replaces the validation of the superseded filter-rail/slots implementation.

## Delivered contract

`@c2n/log-viewer` registers `c2-log-viewer` and exports `LogViewer`, `LogEntry` and `LogFilter`. Behavioral properties: `tabular=true`, `wrap=false`, property-only `columns`. Methods: `appendEntries`, `setFilter`, `clear`, `scrollToEnd`. Readonly counts: `entryCount`, `filteredCount`. No slots, saved-filter state, toolbar, statistics bar or interaction events. `setFilter` supports matching-only filtering and contextual highlighting; matching count is accurate in both modes.

36 CSS variables and ten parts are generated from documented source JSDoc. React/Vue declarations and the AI catalog describe the current contract. Default appearance needs no consumer CSS overrides. Docs and gallery use realistic server access and commercial checkout data. Entry heights come from measured text lines; a cumulative index supports variable-height virtualization. Short tabular cells stick within the tallest cell's row. Plain mode slices visible lines inside tall entries.

## Practical limits

Retained data and its line index remain in memory until clear; the application owns retention. Browser selection/find/printing cover only the virtual window. Use application data for complete export or search. Wrapped text breaks tokens at measured glyph boundaries and tabs display as four spaces. Custom layout geometry must use the documented font/spacing/column variables so the index and displayed content agree.
