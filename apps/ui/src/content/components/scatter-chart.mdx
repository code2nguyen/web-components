The default example plots illustrative product-usage data: weekly active hours against 90-day retention, one series per plan so each segment gets its own colour. The other examples pair Apple R&D expense with annual revenue from the public [SEC Company Facts data](https://data.sec.gov/api/xbrl/companyfacts/CIK0000320193.json). It answers a real question a time-series chart cannot: whether larger investment years also occupy a different revenue range.

## Import

```typescript tag=CodeBlock
import '@c2n/components/chart/scatter-chart'
```

This chart draws with [ECharts](https://echarts.apache.org), a peer dependency it loads on first draw: `npm install echarts`.

`x-field` supplies the horizontal measure and each `c2-chart-series` supplies a vertical measure; a row may carry only one series' field, and the others skip it. Both axes fit the data rather than starting at zero, so a cluster fills the plot. `symbol`, `symbol-size`, `large` and `large-threshold` tune the marks and opt into ECharts' high-volume rendering path. The replay seeds its first observation, waits for `chart-ready`, then interpolates each new point from the preceding year; a streaming UI should use the same readiness boundary before starting a high-frequency feed.
