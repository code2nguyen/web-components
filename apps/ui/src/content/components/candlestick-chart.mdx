The examples use AAPL daily open, high, low and close observations from the public [Nasdaq historical-data service](https://www.nasdaq.com/market-activity/stocks/aapl/historical). The default field convention is `open`, `close`, `low`, `high`; rename those with the four `*-field` attributes when adapting a feed.

## Installation

```bash tag=CodeBlock
npm install @c2n/chart echarts
```

## Usage

```html tag=UsageBlock,package=@c2n/chart
<style>
  .finance-candles,
  .finance-candles-live {
    display: grid;

  }
</style>

<div data-label="Default">

  </div>

```

With no children, the component infers the four OHLC fields. If you declare series explicitly, provide exactly four in open, close, low, high order. Positive and negative candles use the shared chart theme tokens, and the linked tooltip reports the complete session instead of a single mark.
