## Presets

Curated looks for `c2-action-bar`. Open any card in the studio to start from it. The `__container--*` variables
restyle the floating surface, `__label--*` the count, and `__clear--*` the clear button; `__divider--border-left: none`
drops the rule between the count and the actions. Each card sits in a frame standing in for the collection the bar
floats over.
