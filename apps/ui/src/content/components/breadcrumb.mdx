`c2-breadcrumb` shows where the user is in a hierarchy. Every child is one item: use `c2-link-button` with an `href` for the ancestors and either a link button or a plain element for the current page. The last item is marked as the current page automatically (`aria-current="page"`) and styled as text, and a separator is drawn between items, a chevron by default or the content of the `separator` slot. The trail always stays on one row: when it does not fit, items collapse behind an ellipsis in priority order (the current page always, then the first item, then the items closest to the current page), and `max-items` caps the visible count even when there is room. Clicking the ellipsis reveals every item. The whole trail sits in a `nav` landmark labelled "Breadcrumb" (override with `aria-label`).

## Installation

```bash tag=CodeBlock
npm install @c2n/breadcrumb
```

Importing `@c2n/breadcrumb` also registers `c2-link-button`.

Items keep their own behaviour: a `c2-link-button` with `href` is a real anchor, so middle-click and open-in-new-tab work, and one without `href` fires `click`. The breadcrumb only decides which item is current: the last one, unless you put `selected` (or `aria-current`) on another item yourself. Items added or removed later are picked up automatically.

The breadcrumb measures its items and keeps the trail on a single row. When the items do not fit its width, it keeps them in priority order: the current page is always shown, the first item comes next, then the middle items closest to the current page for as long as there is room; everything else sits behind the ellipsis. In a very narrow container that leaves just the ellipsis and the current page. The trail re-measures when the container resizes. `max-items` adds an upper bound: `max-items="3"` never shows more than the first item and the last two, even with room to spare. The ellipsis is a button labelled with the number of hidden items; it expands the trail in place (wrapping onto further rows if needed) and moves focus to the first revealed item.

The breadcrumb styles its items through the link button's own variables, so `--c2-breadcrumb__item--*` (colour, size, padding, radius, hover and current colours) applies to links, the ellipsis and a plain current element alike, and `--c2-breadcrumb__separator--*` sizes and colours the separator. The host is a block that fills its container; size that container to control where the trail collapses.
