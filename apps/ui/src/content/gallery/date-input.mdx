## Calendar popover

`picker="calendar"` opens a themed calendar in place of the browser's date picker, with Today and Clear. It is loaded the first time it opens. Buttons in the `calendar-actions` slot add presets.

<GalleryGrid>

```html tag=MdxCodeBlock,label=Calendar
<style>
  .calendar-field {
    width: 220px;
  }
</style>
<c2-date-input class="calendar-field" picker="calendar" aria-label="Due date" value="2026-09-15"></c2-date-input>
```

```html tag=MdxCodeBlock,label=Presets
<style>
  .calendar-presets {
    width: 220px;
  }
  .calendar-presets .preset {
    --c2-button__container--height: 30px;
    --c2-button__container--padding-left: 10px;
    --c2-button__container--padding-right: 10px;
    --c2-button__container--background-color: transparent;
    --c2-button__container--color: var(--c2-theme--color-on-surface, #18181b);
    --c2-button__container--border: 1px solid var(--c2-theme--color-outline-variant, #e4e4e7);
```

The preset buttons set the value and close the popover:

```ts tag=CodeBlock
field.querySelectorAll('[slot="calendar-actions"]').forEach((button) =>
  button.addEventListener('click', () => {
    field.value = isoDaysFromToday(Number(button.dataset.days))
    field.hideCalendar()
  }),
)
```
