## Presets

Curated looks for `c2-kbd`. Open any card in the studio to start from it. A keycap is mostly four variables — `--c2-kbd--background-color`, `--c2-kbd--border`, `--c2-kbd--border-radius` and `--c2-kbd--box-shadow` — and dropping the shadow is what turns a raised key into a flat inline tag.

<GalleryGrid>

```html tag=MdxCodeBlock,label=Keycap
<c2-kbd>⌘ + K</c2-kbd>
```

```html tag=MdxCodeBlock,label=Flat
<style>
  .flat {
    --c2-kbd--background-color: transparent;
    --c2-kbd--border: 1px solid #d4d4d8;
    --c2-kbd--box-shadow: none;
  }
</style>
<c2-kbd class="flat">Tab</c2-kbd>
```
