## Presets

Curated looks for `c2-code-viewer`. Open any card in the studio to start from it. The frame is `--c2-code-viewer--*` (`background` and `color` override the theme's own), the file-name bar is `__header`, the copy button `__copy`, gutters `__line-numbers`, emphasised rows `__line__highlighted`, and with `theme="css-variables"` the token colours themselves are the `__theme--*` properties.
