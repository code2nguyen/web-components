## Absence calendar

People down the side and a month across: each absence is a bar coloured by its type, `pending` requests are hatched,
`bands` shade the public holidays, and `renderSummary` draws a "who is out" row under the grid that flags the days

```ts tag=CodeBlock
import { html } from 'lit'
import type { Scheduler } from '@c2n/components/scheduler'

const scheduler = document.querySelector<Scheduler>('c2-scheduler')!
// Called once per column (a day here) with the absences over it and every resource.
scheduler.renderSummary = ({ events, resources }) => {
  const out = new Set(events.map((event) => event.resource)).size
  if (!out) return ''
  const short = resources.length - out < 4
  return html`<span part=${short ? 'out short' : 'out'}>${out}</span>`
}
```
