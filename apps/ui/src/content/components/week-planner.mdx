`c2-week-planner` shows a typical week: seven day columns on an hour scale, each event a block from its start to its end
time. It has no dates and no navigation. An event names the weekday it happens on and repeats every week, or, with
`alternate-weeks`, only in odd or even weeks (`weeks: "odd"`), as school and shared-custody schedules do. Today's
column is tinted (`--c2-week-planner__day__today--background`, drawn inside the grid lines) and carries a line at the
current time. Overlapping events cascade, each stepped in from the one before and drawn over it, so the earlier one's
title stays readable, and the hour range (`start-hour`, `end-hour`, 8 to 18 by
default) grows to fit every event.

## Installation

```bash tag=CodeBlock
npm install @c2n/week-planner
```

## Usage

```html tag=UsageBlock,package=@c2n/week-planner
<div data-label="Every week">
  <c2-week-planner
    locale="en-US"
    start-hour="8"
    end-hour="13"
    events='[{"title":"Team stand-up","day":"mon","start":"08:30","end":"09:00"},{"title":"Team stand-up","day":"thu","start":"08:30","end":"09:00"},{"title":"Client workshop","day":"tue","start":"10:00","end":"12:00","color":"#b45309"},{"title":"Design review","day":"tue","start":"11:00","end":"12:30","color":"#be185d"},{"title":"Focus time","day":"fri","start":"09:00","end":"12:00","color":"#52525b"}]'
  ></c2-week-planner>
</div>
<div data-label="Odd and even weeks">
  <c2-week-planner
    heading="Kids’ schedule"
    alternate-weeks
    locale="en-US"

  ></c2-week-planner>

  <c2-week-planner

    start-hour="9"

    <c2-button slot="actions">Add event</c2-button>
    <c2-button slot="actions">Settings</c2-button>
  </c2-week-planner>
</div>
```

## Events

Each entry is `{ id?, title, day, start, end, weeks?, color?, textColor? }`: `day` is `mon` to `sun`, `start` and `end` are 24-hour
`HH:MM` times (`24:00` ends at midnight). Entries whose times are invalid or end before they start are skipped. `color`
is any CSS colour for that block (its text stays white in both themes; add `textColor` for a light `color`); otherwise
`--c2-week-planner__event--background` applies.

## Heading

`heading` puts a title at the start of the header (`--c2-week-planner__title--font-size`,
`--c2-week-planner__title--font-weight`) and becomes the planner's accessible name, unless `aria-label` is set. It is
called `heading` rather than `title` because `title` is the browser's tooltip attribute, which would hover over the
whole planner.

For more than plain text, put your own markup in the `heading` slot: an icon next to the name, a link, or a field
that renames the planner. It replaces the `heading` text inside the same `h2`, and names the planner unless `heading`
or `aria-label` is set.

```html tag=CodeBlock
<c2-week-planner aria-label="Team week">
  <c2-text-field slot="heading" value="Team week" aria-label="Planner name"></c2-text-field>
</c2-week-planner>
```

## Actions

The `actions` slot puts controls of your own at the end of the header, e.g. an "Add event" button or a settings menu,
spaced by `--c2-week-planner__actions--gap`. They sit before the previous/next day arrows on a narrow planner, and
the header shows for them even without a heading or the week switch. The planner leaves what they do to you.

```html tag=CodeBlock
<c2-week-planner heading="Team week">
  <c2-button slot="actions">Add event</c2-button>
  <c2-icon-button slot="actions" aria-label="Settings"><c2-feather-settings></c2-feather-settings></c2-icon-button>
</c2-week-planner>
```

## Odd and even weeks

Alternate weeks are off by default: every entry shows each week and `weeks` is ignored. Add the `alternate-weeks`
attribute to turn them on. `weeks` is then `"all"` (the default), `"odd"` or `"even"`, counted by ISO week number,
where week 1 holds the year's first Thursday, and an **Odd week | Even week** switch appears above the grid: a
segmented `c2-button-group`, styled through its own `--c2-button-group__*` variables set on the planner. It opens on
the kind of the current week, whose button carries the current ISO week number in a `c2-badge`, and every-week
entries appear in both. Set `parity="odd"` or `parity="even"` to choose the view yourself; the switch fires `parity-change` with the kind
now shown. Today's column is only marked while the switch shows the current kind of week.

Blocks are buttons: clicking one, or pressing Enter on it, fires `event-click` with the entry in `event.detail.event`.

## Narrow screens

Below 640px of width the planner shows three days, and below 420px a single day, of a strip that scrolls sideways
and snaps to a day: swipe it on a touch screen, or page through the week with the previous/next arrows that appear in
its header. It opens on today and the hour labels stay in place. The breakpoints follow the planner's own width, not
the viewport's, so a planner in a narrow sidebar switches too.

```html tag=UsageBlock,package=@c2n/week-planner
<style>
  .phone {
    width: 360px;
    max-width: 100%;
  }
  .tablet {
    width: 560px;
    max-width: 100%;
  }
</style>
<div data-label="One day">
  <c2-week-planner
    class="phone"
    heading="Team week"
    locale="en-US"
    start-hour="8"
    end-hour="13"
    events='[{"title":"Team stand-up","day":"mon","start":"08:30","end":"09:00"},{"title":"Team stand-up","day":"thu","start":"08:30","end":"09:00"},{"title":"Client workshop","day":"tue","start":"10:00","end":"12:00","color":"#b45309"},{"title":"Design review","day":"tue","start":"11:00","end":"12:30","color":"#be185d"},{"title":"Focus time","day":"fri","start":"09:00","end":"12:00","color":"#52525b"}]'
  ></c2-week-planner>
</div>
<div data-label="Three days">
  <c2-week-planner
    class="tablet"
    heading="Team week"
    locale="en-US"
    start-hour="8"
    end-hour="13"

```

In a layout that sizes it from its content, such as a centred flex column, the planner takes 720px or the space
available, whichever is smaller; give it a `width` to choose another.

## Language

The planner's text follows `locale` (`fr`, `en-GB`, …) and, when it is not set, the browser's language. The day
columns start on that language's usual first day (Sunday in `en-US`, Monday in `fr` or `en-GB`, Saturday in
`ar-EG`); `week-start` (`monday`, `sunday` or `saturday`) overrides it. Day names,
"today" and "this week" come from the browser's `Intl` data, so they exist in every language; the switch labels
(Odd week, Even week) and the accessible names are built in for English, French, German, Spanish, Italian, Portuguese,
Dutch and Vietnamese, and fall back to English otherwise.

```html tag=UsageBlock,package=@c2n/week-planner
<div data-label="French">
  <c2-week-planner
    alternate-weeks
    locale="fr"
    start-hour="8"
    end-hour="12"
    events='[{"title":"Réunion d’équipe","day":"mon","start":"08:30","end":"09:30"},{"title":"Enfants : piscine","day":"wed","start":"09:00","end":"11:00","weeks":"even","color":"#0f766e"},{"title":"Marché","day":"sat","start":"09:00","end":"10:30","weeks":"odd","color":"#b45309"}]'
  ></c2-week-planner>
</div>
```

```ts tag=CodeBlock
import '@c2n/week-planner'

const planner = document.querySelector('c2-week-planner')!
planner.events = [{ id: 'pickup', title: 'School pick-up', day: 'wed', start: '13:30', end: '17:00', weeks: 'even' }]
planner.addEventListener('event-click', (event) => console.log(event.detail.event.id))
```
