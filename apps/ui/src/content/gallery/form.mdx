<FormListExamplesRuntime />

The rows of the "Rows from data" card are set from script; `rows-change` reports each add, remove and move:

```ts tag=CodeBlock
const lines = document.querySelector('c2-form-list')!
lines.value = [
  { item: 'Design review', hours: '6' },
  { item: 'Component build', hours: '18' },
]
lines.addEventListener('rows-change', (event) => save(event.detail.value))
```

The French card's "Ajouter" and its screen-reader announcements come from the app's translations:

```ts tag=CodeBlock
import { addTranslations } from '@c2n/core/localize.js'

addTranslations({
  fr: {
    'form-list': { add: 'Ajouter', added: 'Ligne {0} ajoutée', removed: 'Ligne {0} supprimée', moved: 'Ligne déplacée en position {0} sur {1}' },
  },
})
```
