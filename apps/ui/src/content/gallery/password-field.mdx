## Presets

The box is one set of variables (`--c2-password-field--border`, `--c2-password-field--background`, `--c2-password-field--border-radius`, `--c2-password-field--min-height`), with `--c2-password-field__hover--*`, `__focus--*` and `__error--*` states on top. The `--c2-password-field__meter--*` variables shape the strength meter, one colour per level (`__meter__weak--color` to `__meter__strong--color`), and the `--c2-password-field__requirement--*` variables the checklist.
