## Presets

Curated looks for `c2-tabs`. Open any card in the studio to start from it. Every look is CSS variables only: the rail (`--c2-tabs--*`), the tabs (`--c2-tabs__tab--*` and their `hover` / `selected` / `focus` / `disabled` states) and the indicator (`--c2-tabs__indicator--*`). Give the indicator a full height and a `bottom` offset and it becomes a pill sliding behind the labels.
