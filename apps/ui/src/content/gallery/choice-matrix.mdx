## Cell content

A cell can show what it stands for beside its control, from `cells` or from `renderCell`; the control and the content
are one label. With `type="radio"`, `use-all` puts a "Use all" button under each column.

## Under a row

A row's `detail-<row>` slot, or `renderRowDetail`, puts a line under it across the matrix: a comment field, a note, a
photo. What a renderer draws sits in the shadow root, so it carries a `part` for the page to style.

<GalleryGrid min="460">

```html tag=MdxCodeBlock,label=Comment under a row
<style>
  .matrix-note {
    width: 100%;
  }
</style>
<c2-choice-matrix type="radio" label="Release checklist" row-header="Check"
  columns='[{"value":"done","label":"Done"},{"value":"blocked","label":"Blocked"},{"value":"skip","label":"Skip"}]'
  rows='[{"value":"tests","label":"Tests green"},{"value":"docs","label":"Docs updated"},{"value":"notes","label":"Release notes"}]'
  value='{"tests":"done","docs":"blocked"}'>
  <c2-textarea class="matrix-note" slot="detail-docs" aria-label="Why the docs are blocked" value="Waiting on the new screenshots."></c2-textarea>
</c2-choice-matrix>
```

The note when blocked sets `renderRowDetail`:

```ts tag=CodeBlock
matrix.renderRowDetail = ({ row, chosen }) =>
  chosen.includes('blocked') ? html`<span part="blocked-note">${row.label} is blocking the launch: add an owner and a date.</span>` : undefined
```

The plan picker sets `renderCell`:

```ts tag=CodeBlock
matrix.renderCell = ({ row, column, checked }) => {
  const price = PRICES[row.value]?.[column.value]
  return price === undefined ? undefined : html`<strong>${money.format(price)}</strong>${checked ? html` <span part="plan-pick">· selected</span>` : ''}`
}
```
