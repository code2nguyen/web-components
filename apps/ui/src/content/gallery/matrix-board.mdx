The custom cards come from `renderItem`, a JavaScript property; the board still draws the card box, its focus ring
and its drag lift:

```ts tag=CodeBlock
import { html } from 'lit'

board.renderItem = ({ item }) => html`
  <c2-avatar name=${item.name} auto-color></c2-avatar>
  <span>${item.name}</span>
  <span>${item.role}</span>
`
board.addEventListener('card-move', ({ detail }) => save(detail.key, { potential: detail.toRow, performance: detail.toColumn }))
```
