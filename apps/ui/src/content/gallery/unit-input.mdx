## Field

The field, the number and the step controls take the `--c2-number-input--*` variables; the unit picker, the unit label
and the equivalent take `--c2-unit-input--*`.

The base quantity card reads `baseValue` whenever the number or the unit changes, whatever unit is selected:

```ts tag=CodeBlock
const stock = document.querySelector('c2-unit-input')!
const show = () => (output.textContent = `Stock: ${stock.baseValue} ${stock.baseUnit?.value}`)
stock.addEventListener('input', show)
stock.addEventListener('unit-change', show)
```

The French card's picker name and equivalent come from the app's translations:

```ts tag=CodeBlock
import { addTranslations } from '@c2n/core/localize.js'

addTranslations({
  fr: {
    'number-input': { decrease: 'Diminuer la valeur', increase: 'Augmenter la valeur' },
    'unit-input': { unit: 'Unité', equivalent: '= {0} {1}', approximately: '≈ {0} {1}' },
  },
})
```
