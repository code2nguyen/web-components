## Presets

The group itself only owns the gap and the `+N` indicator: `--c2-chip-group__overflow--*` sets its pill (height, padding, border, background, colour, type) and the `__hover`/`__focus` states apply when it is an `expandable` button. Style the items through their own `c2-chip` and `c2-badge` variables.

<GalleryGrid>

```html tag=MdxCodeBlock,label=Default
<style>
  .default-group {
    width: 260px;
  }
</style>
<c2-chip-group class="default-group" aria-label="Topics">
  <c2-chip>Design</c2-chip>
  <c2-chip>Engineering</c2-chip>
  <c2-chip>Product</c2-chip>
  <c2-chip>Marketing</c2-chip>
</c2-chip-group>
```
