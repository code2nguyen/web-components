## Presets

The box is one set of variables (`--c2-password-field--border`, `--c2-password-field--background`, `--c2-password-field--border-radius`, `--c2-password-field--min-height`), with `--c2-password-field__hover--*`, `__focus--*` and `__error--*` states on top. The `--c2-password-field__meter--*` variables shape the strength meter, one colour per level (`__meter__weak--color` to `__meter__strong--color`), and the `--c2-password-field__requirement--*` variables the checklist.

## Password generator

`generator` adds a wand beside the eye. It opens a popover with a suggestion drawn from `crypto.getRandomValues`, its strength and entropy, a copy button, and the options: a length and four character classes, or a passphrase of random words. Use password puts it in the field. The popover loads the first time it opens. `generator-options` sets where it starts, and the field's `minlength`, `maxlength` and requirements bound it: a class a requirement asks for stays on. The `--c2-password-field__generator--*` variables style the popover, the `generate-icon` slot replaces the wand and the `generator-actions` slot adds buttons of your own.

`generate()` draws a suggestion without opening the popover, from `generator-options` overridden by its argument, and bounded by the field like the popover is. It does not change the value:

```ts tag=CodeBlock
const field = document.querySelector('c2-password-field')!
field.value = await field.generate({ kind: 'passphrase', words: 4, capitalize: true })
```

A passphrase is drawn from 1,548 common English words (about 10.6 bits each), loaded on first use. Pass `wordList` in `generator-options` to draw from words in the user's language.
