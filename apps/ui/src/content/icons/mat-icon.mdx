# Mat Icon

`c2-mat-icon` is a simple wrapper for Material Icon font component.

## Installation

```bash tag=CodeBlock
npm install @c2n/components
```

## Import

```typescript tag=CodeBlock
import '@c2n/components/mat-icon'
```

`c2-mat-icon` renders ligature text in a Material icon font that it does not load itself. Load one in the app, for example `npm install @fontsource/material-icons` and `import '@fontsource/material-icons'`.

## Examples

The ligature is a bare text node, so it cannot receive a class of its own. Customize it through the host's documented font-size, font-weight, and color properties, or wrap other text-slot content in an element when it needs an independently targetable class.

```html tag=MdxCodeBlock,compact=true,label=Size weight and colour
<style>
  .featured-icon {
    --c2-mat-icon--font-size: 36px;
    --c2-mat-icon--font-weight: 500;
    --c2-mat-icon--color: #2563eb;
  }
</style>
<c2-mat-icon class="featured-icon">home</c2-mat-icon>
```

Use the sliders button on the example, or select any icon in the gallery, to open that icon directly in the configuration studio.

The ligature names the icon. In a button, it goes in the `prefix-icon` or `suffix-icon` slot.

```html tag=MdxCodeBlock,compact=true,label=In a button
<c2-button><c2-mat-icon slot="prefix-icon">add</c2-mat-icon>New item</c2-button>
<c2-button>Continue<c2-mat-icon slot="suffix-icon">arrow_forward</c2-mat-icon></c2-button>
```

```html tag=MdxCodeBlock,compact=true,label=Inline with text
<p>Saved to <c2-mat-icon>folder</c2-mat-icon> Reports, shared with <c2-mat-icon>group</c2-mat-icon> Finance.</p>
```
