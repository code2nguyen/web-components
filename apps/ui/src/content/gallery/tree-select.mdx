## Presets

Curated looks for `c2-tree-select`. Open any card in the studio to start from it. The trigger is the `__button--*`
group, the dropdown the `__list--*` group, and the chips `__chip--*`; the rows themselves are `c2-tree-item`s, styled
with the `--c2-tree-item--*` variables on the same element.
