## Presets

Curated looks for `c2-confirm-dialog`. Each card shows a trigger; open the dialog to see the look. The buttons are `__confirm-button` and `__cancel-button` (with `__destructive` states), the icon is `__icon` and the message `__message`; the frame is the inner modal's `--c2-modal--*` variables. A typed confirmation (`confirm-text`) and a prompt add a field under the message, styled through `__field`, `__label`, `__phrase` and `__error`.

<ConfirmDialogExamplesRuntime />

"Prompt", "Async validation" and "Select in the input slot" open with `prompt()`, which resolves with the value the user confirmed, or `null` when they cancel. A `validate` function returns the message to show, and a promise keeps the confirm button spinning while it settles:

```ts tag=CodeBlock
const dialog = document.querySelector('c2-confirm-dialog')!
const name = await dialog.prompt({
  label: 'File name',
  value: file.name,
  required: true,
  validate: (value) => (value.includes('/') ? 'A file name cannot contain a slash.' : null),
})
if (name !== null) rename(file, name)

// A control in the input slot (here a c2-select) is read instead of the built-in field.
const board = await moveDialog.prompt<string[]>()
```

"No markup" uses the `prompt()` helper, which mounts a temporary dialog:

```ts tag=CodeBlock
import { prompt } from '@c2n/components/confirm-dialog'

const folder = await prompt({ heading: 'New folder', label: 'Folder name', confirmLabel: 'Create', required: true })
```

"En français" sits under `lang="fr"`: the Cancel label and the typed-confirmation instruction show the translation the page registered.

```ts tag=CodeBlock
import { addTranslations } from '@c2n/core/localize.js'

addTranslations({ fr: { 'confirm-dialog': { cancel: 'Annuler', typeToConfirm: 'Saisissez {0} pour confirmer' } } })
```
