`c2-select` is a trigger button plus a popover. The options are plain `c2-list-item` children, so everything you know about list items applies here: `value` identifies an option, `label` gives the trigger a short text when the row content is rich, `disabled` greys a row out, and the `prefix-icon` / `suffix-icon` slots decorate it. Inside the popover the rows live in a `c2-list` that owns the selection, keeps the dropdown open in `multiple` mode and lists every selected label in the trigger. The dropdown is a native popover on the top layer, positioned by `c2-overlay`, so it flips above the trigger near the bottom of the viewport and is never clipped by an `overflow: hidden` parent.

The trigger has no intrinsic width: give the host a `width` (or a grid / flex cell) and the button fills it. Tab to the trigger, then use Space, Enter or the arrow keys to open it.

## Installation

```bash tag=CodeBlock
npm install @c2n/select
```

`@c2n/list-item` is a dependency of the package and is registered for you.

## Handling selection

`selection-change` fires after every pick. `detail.value` is the array of selected values; `detail.data` carries the `data` property of each selected row, handy for keeping the full record next to its id. Set `value` (an array) to change the selection from code, and `open` to show or hide the dropdown.

```ts tag=CodeBlock
const select = document.querySelector('c2-select')

select.addEventListener('selection-change', (event) => {
  console.log(event.detail.value) // ['FR']
  console.log(event.detail.data) // [{ code: 'FR', name: 'France' }]
})

select.querySelector('c2-list-item[value="FR"]').data = { code: 'FR', name: 'France' }
select.value = ['FR']
select.open = true
```

## Theming

Three variable families cover the whole control. `--c2-select__button--*` is the trigger, with `__hover`, `__open`, `__focus` and `__disabled` states; `--c2-select__list--*` is the dropdown container (background, border, radius, shadow, padding, max height); and because the rows are your own children, `--c2-list-item--*` set on the select cascades into every option.

```css tag=CodeBlock
c2-select.brand {
  --c2-select__button--border-top-left-radius: 999px;
  --c2-select__button--border-top-right-radius: 999px;
  --c2-select__button--border-bottom-left-radius: 999px;
  --c2-select__button--border-bottom-right-radius: 999px;

  --c2-select__list--border-top-left-radius: 12px;
  --c2-select__list--border-top-right-radius: 12px;
  --c2-select__list--border-bottom-left-radius: 12px;
  --c2-select__list--border-bottom-right-radius: 12px;

  --c2-list-item__selected--background: #fdf2f8;
  --c2-list-item__selected--color: #be185d;
}
```

Every variable, with its default, is listed on the API tab, and the Gallery tab has ready-made looks to start from.
