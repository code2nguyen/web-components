`renderActions` is a property, so the row actions above are set from a script. It receives the requirement, its status
and its files, and returns anything Lit renders:

```ts tag=CodeBlock
import { html } from 'lit'

checklist.renderActions = ({ requirement, status }) =>
  status === 'approved' || status === 'in-review'
    ? html`<c2-button aria-label=${`View ${requirement.label}`} @click=${() => openDocument(requirement.id)}>View</c2-button>`
    : undefined
```
