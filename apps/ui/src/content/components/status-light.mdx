`c2-status-light` shows the state of a deployment, a service, a job or an invoice as a coloured dot followed by its label. The label in the default slot carries the meaning, so the colour is never the only signal. `tone` picks one of six colours (`neutral`, `primary`, `info`, `success`, `warning`, `danger`) and `pulse` adds a soft ring for a state in progress, stilled under reduced motion. With an empty label the light is a bare dot: give it an `accessible-label` and it is read as an image of that name. Size, spacing and shape are CSS variables, and an icon in the `dot` slot replaces the dot and takes the tone colour.

## Import

```typescript tag=CodeBlock

```
