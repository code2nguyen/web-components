## Presets

Rows are tinted by `--c2-diff-viewer__line__added--background-color` and `__line__removed--background-color`, the changed words inside them by the `__word__*` variables, and the line numbers by `__line-number__*`. Folded runs are the `__fold--*` variables; the code font, size and wrapping are `__code--*`.

<GalleryGrid>

```html tag=MdxCodeBlock,label=Default
<c2-diff-viewer
  original="name: shop
selectors:
  item: .card
  price: .price
"
  modified="name: shop
selectors:
  item: article.product
  price: .price
  title: h2
"
></c2-diff-viewer>
```
