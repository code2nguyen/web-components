`c2-in-view` watches its content scroll in and out of view, like Web Awesome's intersection observer, Framer Motion's `whileInView` and the "load more" sentinel at the end of a feed. It fires `enter` and `leave`, exposes the `in-view` state to CSS, and can reveal its content with a fade and a slide, all set with CSS variables.

## Import

```typescript tag=CodeBlock
import '@c2n/components/in-view'
```

## Usage

Scroll the list: each card fades and rises as it comes into view.

```html tag=UsageBlock,package=@c2n/in-view
<style>
  .in-view-demo {
    --c2-scroll-area--max-height: 260px;
    width: 280px;
  }
  .in-view-demo .reveal {
    --c2-in-view__hidden--opacity: 0;
    --c2-in-view__hidden--transform: translateY(24px);
  }
  .in-view-demo .card {
    margin: 0 0 12px;
    padding: 24px 16px;
    border-radius: 8px;
    background: var(--c2-theme--color-surface-container, #f4f4f5);
  }
</style>
<div data-label="Reveal on scroll">
  <c2-scroll-area class="in-view-demo" label="Cards"><c2-in-view class="reveal"><p class="card">Card 1</p></c2-in-view><c2-in-view class="reveal"><p class="card">Card 2</p></c2-in-view><c2-in-view class="reveal"><p class="card">Card 3</p></c2-in-view><c2-in-view class="reveal"><p class="card">Card 4</p></c2-in-view><c2-in-view class="reveal"><p class="card">Card 5</p></c2-in-view><c2-in-view class="reveal"><p class="card">Card 6</p></c2-in-view><c2-in-view class="reveal"><p class="card">Card 7</p></c2-in-view><c2-in-view class="reveal"><p class="card">Card 8</p></c2-in-view></c2-scroll-area>
</div>
```

### Events and state

`enter` fires when the content comes into view and `leave` when it goes, each with `{ ratio }`, the share of it that shows; `inView` reads the state now. `threshold` (0 to 1) is how much must show to count, and `root-margin` grows or shrinks the viewport, as CSS margins. `once` stops watching after the first entry, and `disabled` stops watching.

The state is a CSS custom state, not an attribute: style it with `c2-in-view:state(in-view)`. Content inside a scrolling container, such as a `c2-scroll-area`, counts as in view only where the container shows it.

### Reveal

The reveal is CSS: `--c2-in-view__hidden--opacity` and `--c2-in-view__hidden--transform` hold the content's look while it is out of view (by default, none), and it eases to normal as it enters, over `--c2-in-view--transition-duration`. `--c2-in-view--transition-delay` staggers a row. Under `prefers-reduced-motion` the content simply shows.

### Loading more

Put one at the end of a list, with a margin so it fires before the reader gets there:

```html tag=CodeBlock
<c2-in-view root-margin="300px" id="more"></c2-in-view>
<script>
  document.getElementById('more').addEventListener('enter', () => loadNextPage())
</script>
```
