## Presets

Curated looks for `c2-details`. Open any card in the studio to start from it. The frame is `--c2-details--*`, the header is `--c2-details__header--*` with `__icon`, `__content` (the second header row), `__hover`, `__open`, `__focus` and `__disabled` states, and the body is `--c2-details__content--*`. Panels that share a `name` form an exclusive accordion.

## Collapse

`headless` draws the content alone, with no summary row and no frame, so the panel becomes a collapse that a control elsewhere on the page opens. A `c2-button` (or a native button) needs no script: `commandfor` names the panel and `command` is `--toggle`, `--open` or `--close`; the panel keeps that button's `aria-expanded` in step, and `c2-button` hands it to its inner button. Invoker commands are Baseline since December 2025 (Chrome 135, Firefox 144, Safari 26.2); in an older browser the panel runs the button's command on click itself. Any other control drives `expanded` or `toggle()` and listens for `toggle`, as the switch card does:

```ts tag=CodeBlock
import type { Details } from '@c2n/components/details'
import type { Switch } from '@c2n/components/switch'

const toggle = document.querySelector<Switch>('c2-switch')!
const panel = document.querySelector<Details>('c2-details[headless]')!
toggle.addEventListener('change', () => (panel.expanded = toggle.checked))
// Find-in-page can open the panel: keep the switch in step.
panel.addEventListener('toggle', (event) => (toggle.checked = event.newState === 'open'))
```
