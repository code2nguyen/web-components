## Presets

Curated looks for `c2-floating-panel`, each in a positioned box with `boundary="parent"` so it stays inside the card. `--c2-floating-panel--inset`, `--width` and `--height` set where a panel first appears; the box variables (`--background`, `--border`, `--border-radius`, `--box-shadow`) and the `__header`, `__title` and `__button` groups set its look; `__docked` and `__maximized` place it when minimised or maximised.
